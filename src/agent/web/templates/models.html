工作方式说明

  • 默认模型：所有写作、讨论、大纲等生成任务的默认调用模型（优先级高于 .env）。
  • 按次切换：实时写作间里可临时指定本次写章使用的模型，不影响默认设置。
  • 兼容规则：.env 中的嵌入模型（EMBEDDING_*）、搜索等工具配置仍然生效，不受影响。
  • 连通性测试：保存后建议先「测试」，确认端点、Key、模型 ID 三者可用。
