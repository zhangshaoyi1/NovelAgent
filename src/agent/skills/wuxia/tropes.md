# 武侠爽点套路库

> 每个套路提供模板，Agent 写作时按情境调用。

## 1. 比武打脸

**触发**：主角被看不起/被挑衅
**结构**：
1. 对手展示武功/门派优越感，出言不逊
2. 主角隐忍或低调应战
3. 比武中主角展露真实实力/隐藏招式
4. 对手一招落败，难以置信
5. 旁观者震惊，重新评估主角

**要点**：反差要大，落败要干脆，不超过 2 章。

## 2. 奇遇传功

**触发**：主角陷入瓶颈或绝境
**结构**：
1. 主角机缘巧合进入隐秘之地（悬崖/古洞/密室）
2. 发现前辈高人遗骸或机缘
3. 获得绝世武功秘籍/传功/神兵
4. 修习后实力大涨
5. 破关而出，震惊江湖

**要点**：奇遇要合理铺垫，不能凭空天降；传功需有代价或考验。

## 3. 恩怨清算

**触发**：积累的仇恨到爆发点
**结构**：
1. 仇人势力强大，主角隐忍蓄力
2. 主角武功大成/找到仇人弱点
3. 周密布局，逐一清算
4. 最终决战场面宏大
5. 恩怨了结，江湖震动

**要点**：清算过程要有智谋，不能纯靠武力；仇恨要铺垫充分。

## 4. 仗剑行侠

**触发**：主角路见不平
**结构**：
1. 主角偶遇不平之事（欺压/陷害/劫掠）
2. 主角暗中观察，了解始末
3. 关键时刻出手相助
4. 以巧妙手段化解危机
5. 受助者感激，江湖传名

**要点**：行侠要符合主角性格，不能圣人化；可埋伏笔（受助者日后回报）。

## 5. 红颜知己

**触发**：主角遇到旗鼓相当的异性
**结构**：
1. 初遇（误会/冲突/合作）
2. 并肩经历危机
3. 互相欣赏武功/心性
4. 感情暗生但含蓄
5. 关键时刻以命相护

**要点**：感情要自然发展，不能一见钟情；红颜须有独立人格与武功。

## 6. 以弱胜强

**触发**：主角面对远超自己的对手
**结构**：
1. 强敌压迫，主角陷入绝境
2. 主角冷静分析对手破绽
3. 利用环境/智谋/特殊手段
4. 关键一击命中弱点
5. 险胜后重伤但存活

**要点**：胜得要合理，不能开挂；代价要真实（重伤/消耗）。

## 7. 门派大比

**触发**：武林大会/门派论剑
**结构**：
1. 各方高手云集
2. 主角低调参赛
3. 逐轮晋级，展露实力
4. 决赛对手是强敌/仇人
5. 一战成名，江湖地位确立

**要点**：比赛过程要有起伏，不能一路碾压；每轮展示不同武功。

## 8. 绝境突破

**触发**：主角生死关头
**结构**：
1. 主角被逼入绝境
2. 生死一线间回忆/领悟
3. 武学瓶颈瞬间突破
4. 实力暴涨反杀
5. 突破后有新的感悟

**要点**：突破要有铺垫（前文有卡关），不能凭空顿悟；突破后不能无敌。

## 9. 江湖成名

**触发**：主角做了震动江湖的大事
**结构**：
1. 主角完成壮举（救驾/灭魔/夺宝）
2. 消息传遍江湖
3. 各方势力重新评估
4. 江湖诨号/排名出现
5. 新的挑战随之而来

**要点**：成名要有过程，不能一蹴而就；成名后引来更强对手。

## 10. 武学悟道

**触发**：主角武学遇到瓶颈
**结构**：
1. 主角卡在某个境界/招式
2. 经历事件触发感悟（自然/人事/生死）
3. 顿悟武学真意
4. 招式/境界提升
5. 格局打开，视角变化

**要点**：悟道要有哲学意味，结合武侠精神（侠/义/道）。
