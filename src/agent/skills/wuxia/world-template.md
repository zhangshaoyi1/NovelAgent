# 武侠境界体系模板

> 此片段在 M1 配置阶段注入 world.md，并标记为冻结字段。

## 武功境界体系（冻结字段，修改需解冻命令）

| 境界 | 阶段 | 战力区间 | 特征 |
|---|---|---|---|
| 三流 | 入门 | 1-5 | 会基本拳脚，无内力 |
| 二流 | 入门 | 5-15 | 初窥内力门径 |
| 一流 | 中坚 | 15-40 | 内力小成，可催动招式 |
| 后天 | 中坚 | 40-100 | 内力大成，招式精熟 |
| 先天 | 高阶 | 100-300 | 先天真气，可隔空伤人 |
| 宗师 | 高阶 | 300-800 | 开宗立派，自创武学 |
| 大宗师 | 顶峰 | 800-2000 | 武学巅峰，一派之祖 |
| 化境 | 终极 | 2000+ | 摘叶飞花皆可伤人，传说之境 |

## 力量体系

- **内力**：武功根基，分阴/阳/刚/柔/五行属性
- **招式**：分拳掌、刀剑、枪棍、暗器、奇门五大类
- **轻功**：身法移动，影响闪避与追击
- **外功**：筋骨皮肉锤炼，硬功防御
- **内功心法**：决定内力属性与成长上限，分凡品/良品/上品/绝品/仙品

## 兵器谱系

- **凡兵**：普通铁器
- **利刃**：精钢打造，削铁如泥
- **名器**：名匠所铸，有铭文
- **神兵**：天外陨铁或千年寒铁所铸，认主
- **上古神兵**：传说之物，自带属性加成

## 江湖势力框架

- **六大派**：少林、武当、峨眉、昆仑、华山、崆峒（可调整）
- **帮会**：丐帮、盐帮、漕帮等地方势力
- **世家**：武林世家，家传武学
- **朝廷**：锦衣卫、东厂等官方势力
- **魔教**：邪派势力
- **散人**：无门无派的江湖游侠
- **隐世高人**：不问世事的高手
