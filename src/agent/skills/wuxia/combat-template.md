# 武侠战斗模板

> 战斗章节走此模板，重招式技巧与内力博弈。

## 四段结构

### 1. 起手（约 20%）
- 双方亮明身份/来意
- 起手式试探
- 互探深浅，观察招式路数
- **要点**：展示双方武学流派与性格

### 2. 交锋（约 30%）
- 招式往来，互有攻守
- 内力碰撞，气势交锋
- 环境因素介入（地形/兵器/旁观者）
- **要点**：招式描写要有画面感，体现武学特色

### 3. 变招（约 30%）
- 关键转折出现
  - 主角亮出绝招/底牌
  - 对手露出破绽
  - 主角以智谋变招
  - 环境被利用（借势/借物）
- **要点**：转折要合理，不能凭空开挂

### 4. 决胜（约 20%）
- 一招定胜负
- 战后收束
- 胜负原因点明
- 收获/代价展示
- **要点**：决胜要干脆，点明胜负关键

## 智斗元素（必须包含至少一项）

- **招式克制**：以巧破力，以快打慢
- **心理博弈**：虚招诱敌、激将、示弱
- **环境利用**：地形、光线、声音、机关
- **信息差**：隐藏实力、保留绝招
- **借力打力**：利用对手力量、第三方介入
- **破绽捕捉**：观察对手招式漏洞

## 招式描写要求

- **命名**：招式名要有意境（如"白鹤亮翅""惊涛拍岸"）
- **画面**：动作有画面感，避免流水账
- **内力**：体现内力属性与境界差距
- **节奏**：快慢相间，张弛有度
- **音效**：适当加入兵器碰撞/风声等感官描写

## 禁忌

- 流水账式动作描写（"他出一拳，对方挡住，他又出一拳"）
- 主角无脑强推，纯靠内力碾压
- 反派降智送人头
- 招式没有名字，只写"一招攻去"
- 战斗过程超过 2 章不收尾（除非是大高潮）
- 越级战斗无合理手段（金手指/智谋/破绽）

## 境界战力校验

战斗前必须校验：
- 双方境界差距（参考境界战力表）
- 主角是否有合理手段对抗高境界对手
- 金手指使用是否符合登记
- 是否越级（需金手指/智谋/破绽支持）
- 兵器是否匹配（凡兵对神兵需有补偿）

## 兵器对决特殊规则

- 刀剑对决：注重招式精妙与速度
- 拳掌对兵器：需有特殊手段（空手入白刃/毒/暗器）
- 重兵器对轻兵器：力量与速度的博弈
- 神兵加成：明确战力提升幅度，不能无限放大
