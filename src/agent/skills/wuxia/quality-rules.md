# 武侠题材层质量规则

> 由 quality_checker.register_genre_rules 注册。

## 规则清单

### G-01 武功推进频率
- **检查**：每 N 章（默认 10 章）必须有武功境界或江湖地位推进
- **严重度**：warn
- **修订提示**：长时间无武功/地位推进，读者会感到拖沓

### G-02 战斗模板合规
- **检查**：战斗章节是否符合四段结构（起手→交锋→变招→决胜）
- **严重度**：block
- **修订提示**：战斗章节需按起手→交锋→变招→决胜四段结构组织

### G-03 智斗元素
- **检查**：战斗章节是否包含至少一项智斗元素
- **严重度**：block
- **修订提示**：战斗需包含招式克制/心理博弈/环境利用/信息差/借力打力/破绽捕捉之一

### G-04 境界战力校验
- **检查**：战斗双方境界差距是否合理，主角越级是否有金手指/智谋支持
- **严重度**：block
- **修订提示**：主角越级战斗需有金手指/绝招/智谋/破绽等合理手段

### G-05 金手指使用合规
- **检查**：金手指使用是否符合登记的成长/代价/上限
- **严重度**：block
- **修订提示**：金手指使用超出登记范围，需修订或更新登记

### G-06 爽点节奏
- **检查**：每 N 章（默认 5 章）至少一个爽点（比武打脸/奇遇/行侠等）
- **严重度**：warn
- **修订提示**：长时间无爽点，读者流失风险

### G-07 反派智商
- **检查**：反派是否有合理动机和智商
- **严重度**：warn
- **修订提示**：反派降智，需补充合理动机或智斗表现

### G-08 招式命名
- **检查**：战斗中的招式是否有命名，而非泛泛描写
- **严重度**：warn
- **修订提示**：招式需有名称（如"白鹤亮翅"），不能只写"一招攻去"

### G-09 江湖氛围
- **检查**：是否体现江湖气息（门派/恩怨/义气/切口等元素）
- **严重度**：warn
- **修订提示**：缺少江湖氛围，需融入门派/恩怨/义气等武侠元素

### G-10 侠义精神
- **检查**：主角行为是否符合侠义精神（不能滥杀/无义/失信）
- **严重度**：warn
- **修订提示**：主角行为偏离侠义，需调整或给出合理动机
