# 历史科技文术语表

## 科技与工业
- **科技树**：科技解锁的层级链条，逐级推进
- **工坊**：手工生产的作坊，工业化的起点
- **水力机械**：水轮驱动的机械，前蒸汽时代核心动力
- **水泥/琉璃/肥皂/蒸馏酒**：典型早期变现产品
- **火药武器**：震天雷/火铳/火炮，军事代差的来源
- **焦炭炼铁**：冶炼升级的关键节点
- **工业化体系**：原料-能源-机器-运输的完整链条

## 钱粮兵
- **钱袋子**：商业网络与税收，一切行动的燃料
- **粮道**：战争与治理的生命线
- **兵源**：流民/矿徒/军户，练兵的原料
- **盐铁**：古代命脉产业，也是最大阻力来源

## 朝堂与制度
- **朝堂派系**：帝党/太子党/权臣/清流/宦官
- **科举**：寒门上升通道，主角可用可改
- **变法/新政**：制度层面改革的统称
- **世家门阀**：既得利益集团，中期最大阻力
- **屯田**：战时生产制度
- **开关通商**：外贸与海关，后期财源

## 军制
- **卫所/府兵/募兵**：古代兵制类型
- **参谋制/军功爵**：主角引入的现代组织改良
- **辎重营/工兵**：技术型兵种

## 其他
- **蝴蝶效应**：历史改变引发的连锁反应，需登记
- **知识差**：主角与现代知识的代差优势
- **暴露风险**：超前知识引起猜忌/妖异化的风险
- **民心**：治理成果的终极变现
