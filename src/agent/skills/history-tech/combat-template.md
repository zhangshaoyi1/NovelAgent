# 历史科技文冲突/战争模板

> 本题材对抗分两套模板：战场对决与朝堂博弈，均走四段结构。

## A. 战场对决模板

### 1. 布局（约 20%）
- 敌我态势与情报盘点
- 主角定策（地形/后勤/新式武器运用）
- **要点**：胜机要在开打前展示给读者，赢要赢得可预期

### 2. 交锋（约 30%）
- 前哨接触，旧式战法胶着
- 敌方气势与数量优势施压
- **要点**：先抑后扬，让压力真实存在

### 3. 变数（约 30%）
- 主角新式手段入场（火器齐射/工兵破阵/骑兵奔袭后勤）
- 敌方应对与再次反扑
- 关键小人物表现（主线配角高光）
- **要点**：新式战法要写出对旧战法的具体克制逻辑

### 4. 定局（约 20%）
- 决定性一击，溃败追击
- 战果清点（俘虏/缴获/阵亡）
- 战略影响扩散（朝野震动/外敌胆寒）
- **要点**：伤亡要真实，赢得干净但不失代价

## B. 朝堂博弈模板

### 1. 布局（约 20%）
- 各方立场与利益盘点
- 主角的目标与可让渡项
- **要点**：博弈是利益计算，先亮底牌清单

### 2. 交锋（约 30%）
- 发难/弹劾/提案，舆论造势
- 阵营站队，拉拢与施压
- **要点**：每方发言都要服务自身利益，禁止无立场嘴炮

### 3. 变数（约 30%）
- 关键证据/实绩/变量入场
- 中间派转向
- 幕后交易与妥协
- **要点**：转向要有利益逻辑，不是主角光环

### 4. 定局（约 20%）
- 拍板/表决/圣裁
- 得失清算（得了什么、让了什么）
- 败方的报复种子埋下
- **要点**：朝堂没有全胜，每次胜利都要付出可见代价

## 禁忌

- 战争场面人数与后勤失真（三千人打十万人还全胜无代价）
- 权谋对手集体降智
- 科技武器万能化，无视时代基础制约
- 主角立场全知全能，永不犯错

## 战力/势力校验

对决前必须校验：
- 双方兵力/钱粮/地理数据是否前后一致
- 新式武器数量与产能是否匹配工坊设定
- 朝堂各方立场是否延续前文
- 金手指知识是否在登记范围内
