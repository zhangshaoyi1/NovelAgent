# 历史科技文爽点套路库

> 每个套路提供模板，Agent 写作时按情境调用。

## 1. 技惊四座

**触发**：主角展示超前技艺/见识
**结构**：
1. 场合刁难（比试/质疑/考校）
2. 主角淡然应对
3. 展示过程，细节扎实
4. 行家震撼（行家反应比外行更爽）
5. 名声与机会随之而来

**要点**：技艺展示要有可信的工艺细节，不能一笔带过。

## 2. 点石成金

**触发**：缺钱，需要第一桶金
**结构**：
1. 资金困境具体化（欠债/被逼婚/军费）
2. 选定变现项目（盐/皂/玻璃/酒）
3. 克服制作难点（工艺/原料/保密）
4. 产品面市，供不应求
5. 钱袋子解决，引来觊觎埋线

**要点**：变现闭环要完整（成本-渠道-对手反应），不能只写数钱。

## 3. 朝堂论战

**触发**：新政/新学触动旧利益
**结构**：
1. 反对派发难，引经据典
2. 主角以实绩与逻辑回击
3. 关键证据/数据扭转风向
4. 权威者拍板支持
5. 政策落地，阻力转为暗中反扑

**要点**：论战要有真实说服力，反派论点不能是纯稻草人。

## 4. 练兵强军

**触发**：外敌压力/需要自保武力
**结构**：
1. 接手烂摊子（老弱残兵/新募流民）
2. 现代练法落地（纪律/伙食/军械）
3. 小规模校验（剿匪/边仗）
4. 战力质变，以少胜多
5. 军功到手，兵权成为底气

**要点**：练兵改革要写出"为什么能成"（钱/制度/技术），不能只靠主角威望。

## 5. 基建兴国

**触发**：地盘扩大，需要治理
**结构**：
1. 治理痛点（路/粮/疫/税）
2. 现代方案适配改造
3. 工程推进中的自然/人为阻碍
4. 建成，民生数据可见改善
5. 民心归附，地盘固化

**要点**：基建成果要落到具体的人（某个流民家庭的生活变化）。

## 6. 破格提拔 / 知遇

**触发**：大人物注意到主角才华
**结构**：
1. 主角身份低微但崭露锋芒
2. 大人物试探考校
3. 对答/实绩折服
4. 破格给予平台资源
5. 随之卷入更高层的棋局

**要点**：知遇要互惠（大人物也有所图），不能纯金手指式好运。

## 7. 挫败与反杀

**触发**：旧势力暗算（栽赃/断粮/兵祸）
**结构**：
1. 阴招发动，主角陷入被动
2. 主角早有布置或快速止损
3. 顺藤摸瓜揪出主使者
4. 借势反杀，一举清除
5. 阻力换挡升级（更高层对手登场）

**要点**：反杀的布置要提前埋线，赢在读者看得见的地方。

## 8. 文明代差碾压

**触发**：科技体系成熟，与旧势力/外敌总对决
**结构**：
1. 决战前力量对比悬殊（旧视角）
2. 新式武器/组织体系的首次全量展示
3. 一边倒的战场表现
4. 天下震动，旧秩序崩塌
5. 新制度/新纪元开启

**要点**：碾压是全书积累的总兑现，必须让每个阶段性铺垫都派上用场。
