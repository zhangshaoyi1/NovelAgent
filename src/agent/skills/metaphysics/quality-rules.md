# 题材层质量规则

> 由 quality_checker.register_genre_rules 注册。

## 规则清单

### G-01 玄学自洽
- **检查**：体系有内部逻辑不矛盾
- **严重度**：block
- **修订提示**：设定随意拼凑

### G-02 专业感
- **检查**：鉴宝/医理细节到位
- **严重度**：warn
- **修订提示**：外行描写掉价

### G-03 打脸节奏
- **检查**：每 N 章至少一鉴宝/医道打脸
- **严重度**：warn
- **修订提示**：长期无爽点

### G-04 代价合理
- **检查**：天眼/神医使用有反噬
- **严重度**：warn
- **修订提示**：无代价金手指

### G-05 医德底线
- **检查**：神医济世有原则
- **严重度**：warn
- **修订提示**：无差别救人失格

### G-06 不迷信堆砌
- **检查**：玄学服务剧情非说教
- **严重度**：warn
- **修订提示**：满篇术语冗长

### G-07 战力/价值对标
- **检查**：法器/丹药品级清晰
- **严重度**：block
- **修订提示**：价值崩坏

### G-08 配角智商
- **检查**：伪大师有手段不降智
- **严重度**：warn
- **修订提示**：反派送人头
