# 爽点套路库

> 每个套路提供模板，Agent 写作时按情境调用。

## 1. 鉴宝捡漏

**触发**：地摊/拍卖偶遇
**结构**：
- 以眼力识真
- 低价收入
- 专家打眼
- 价值兑现
**要点**：鉴宝要有专业细节

## 2. 神医救人

**触发**：疑难绝症
**结构**：
- 望闻问切定位
- 奇方逆天
- 打脸庸医
- 声望攀升
**要点**：医道要合乎基本理法

## 3. 风水改运

**触发**：凶宅/败局
**结构**：
- 堪舆找病
- 布局化解
- 运势回转
- 主家感恩
**要点**：风水要自洽有依据

## 4. 相术识人

**触发**：识破伪装
**结构**：
- 观相断性
- 揭穿伪善
- 避祸趋吉
- 反制对手
**要点**：相术服务识人

## 5. 打脸伪大师

**触发**：遇招摇撞骗
**结构**：
- 当场验真
- 揭其破绽
- 挽回名誉
- 立威
**要点**：打脸要有专业压制

## 6. 秘传现世

**触发**：古老传承现
**结构**：
- 得秘籍/法器
- 研习大成
- 济世或扬名
- 门派重整
**要点**：秘传要有传承感
