# 女频言情术语表

## CP 与情感概念
- **CP**：配对（couple），本书核心情感线
- **HE/BE**：Happy Ending / Bad Ending，默认 HE
- **双向奔赴**：双方主动走向对方
- **口是心非**：嘴上否认、行动诚实的经典张力
- **心动瞬间**：好感的具体触发事件，必须有细节承载
- **名场面**：高情感浓度的标志性场景（撑伞/背身/雪中对视等）

## 关系阶段
- **初遇**：第一印象，需记忆点
- **拉扯期**：试探与暧昧的反复
- **定情**：关系正式确立的事件
- **考验期**：外部阻力集中爆发
- **双向奔赴**：终局阶段

## 人设类型
- **女主**：清醒/坚韧/飒爽/软萌/大女主，禁止纯恋爱脑
- **男主**：外冷内热/病娇/腹黑/忠犬/少年感，需有隐藏面
- **情敌**：需有合理动机，禁止纯恶毒工具人
- **助攻**：闺蜜/长辈，推动信息流动

## 古言专用
- **门第**：家族等级，婚姻阻力来源
- **赐婚**：皇权强制婚姻，常见开局
- **和离/休妻**：古代婚姻解除方式
- **侯府/王府**：贵族宅邸等级
- **嫡庶**：嫡出庶出的地位差
- **表姑娘/贵女**：常见女性角色身份

## 现言专用
- **联姻**：家族利益婚姻
- **豪门**：财富阶层设定
- **职场线**：事业与感情的双线结构
- **原生家庭**：现代言情的核心阻力源之一

## 穿越/重生专用
- **知识差金手指**：现代知识在古代变现
- **先知**：重生的信息优势
- **蝴蝶效应**：改变历史的连锁反应，需登记上限
