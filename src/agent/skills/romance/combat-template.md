# 女频言情情感对峙模板

> 本题材无武力战斗；关键冲突（摊牌/对峙/公开交锋）走此模板。

## 四段结构

### 1. 试探（约 20%）
- 双方带着立场/情绪入场
- 绵里藏针的对话，表面客气
- **要点**：对话要留潜台词，禁止直球吵架开场

### 2. 激化（约 30%）
- 关键信息/误解被摆上台面
- 情绪逐步升温，旧账浮现
- 旁观者/环境压力介入
- **要点**：激化要有层次，从克制的委屈到失控的爆发

### 3. 摊牌（约 30%）
- 核心矛盾点破（真相/心意/底线）
- 双方亮出真实态度
- 至少一方做出情感让步或行动证明
- **要点**：摊牌内容必须是读者期待已久的那个信息，不能和稀泥

### 4. 余波（约 20%）
- 关系状态明确改变（更近或决裂）
- 双方独处时的心理余震
- 留下下一阶段情感的钩子
- **要点**：余波比爆发更见情感深度，禁止摊牌后立即若无其事

## 张力元素（每场对峙至少一项）

- **信息差**：一方知道的真相压在对话底下
- **身份差**：阶层/立场让真心话不能直说
- **第三者在场**：公开场合的克制与暗流
- **旧事引用**：用之前的具体细节击中对方
- **道具承载**：定情物/旧信/伤疤等实体记忆点

## 禁忌

- 为吵而吵，吵完无信息增量
- 误会靠"不听解释"硬撑超过 5 章
- 情敌戏份挤压主线 CP 互动
- 女主全程被动挨打无反击

## 情感一致性校验

对峙前必须校验：
- 双方当前关系阶段（阶段表冻结字段）
- 本次冲突是否服务情感弧线
- 让步/和解是否符合双方人设
- 是否与上一场情感事件的余波衔接
