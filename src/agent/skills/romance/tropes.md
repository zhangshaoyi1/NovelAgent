# 女频言情情感套路库

> 每个套路提供模板，Agent 写作时按情境调用。

## 1. 心动名场面

**触发**：男主做出超出预期的举动
**结构**：
1. 女主处于困境/尴尬/危险
2. 男主以不张扬的方式介入（撑伞/解围/兜底）
3. 细节特写（手/眼神/语气）
4. 女主心跳失控，嘴上否认
5. 事后回味，记忆点钉死

**要点**：心动要有具体细节承载，不能空喊"好帅"。

## 2. 吃醋

**触发**：第三方靠近其中一方
**结构**：
1. 情敌/暧昧对象出现
2. 另一方表面平静、行为反常
3. 摩擦升级，口是心非的对话
4. 醋意爆发（拦人/宣示/失态）
5. 事后心虚与关系推进

**要点**：吃醋是双向确认的替代品，火候要轻，别演成狗血撕扯。

## 3. 双向暗恋 / 双向奔赴

**触发**：双方互有好感但都在等
**结构**：
1. 各自视角铺垫在意对方的证据
2. 错位误会（以为对方无意）
3. 一个契机让证据链合并
4. 双方同时/先后摊牌
5. 关系质变

**要点**：双视角信息差是最大爽点，摊牌前的错位感要拉满。

## 4. 误会与和解

**触发**：信息差/第三者挑拨/立场对立
**结构**：
1. 误会产生（必须有合理来源）
2. 冷战期双方各自煎熬（穿插在意对方的细节）
3. 真相线索浮现
4. 解释与爆发
5. 和解，关系比之前更近一层

**要点**：误会存续不超过 5 章；和解必须伴随至少一个情感让步。

## 5. 身份揭晓

**触发**：隐藏身份（世子/总裁/恩人/仇人之后）暴露
**结构**：
1. 身份伏笔持续埋设
2. 危机时刻被动暴露或主动坦白
3. 对方震惊与重新审视
4. 短暂的信任危机
5. 接纳，身份成为助力

**要点**：身份揭晓是中期大高潮，之前的伏笔必须能对上。

## 6. 契约起头 / 先婚后爱

**触发**：利益捆绑（联姻/契约婚姻/交易）
**结构**：
1. 契约成立，约法三章
2. 同居/共事中破戒瞬间累积
3. 某一方先越界（吃醋/护短）
4. 契约名存实亡
5. "违约"摊牌，关系转正

**要点**：破戒瞬间是核心资产，每次都要比上一次更进一步。

## 7. 守护与反转

**触发**：女主陷入大危机（构陷/家族倾覆/生死）
**结构**：
1. 危机爆发，孤立无援
2. 女主自救展示韧性（不纯等人救）
3. 男主雷霆驰援
4. 并肩反转局面
5. 危机后情感质变

**要点**：女主必须先自救，男主是助力不是解药。

## 8. HE 收束

**触发**：全书最终危机解决
**结构**：
1. 最终阻力消解（仇解/误会清/身份定）
2. 情感高潮（告白/婚礼/重逢）
3. 呼应开头的记忆点
4. 主要配角线交代
5. 生活化尾声

**要点**：结尾必须回收开头的心动记忆点，形成闭环。
