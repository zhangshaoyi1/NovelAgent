# 修仙爽点套路库

> 每个套路提供模板，Agent 写作时按情境调用。

## 1. 打脸

**触发**：主角被看不起/被欺辱
**结构**：
1. 反派/路人展示优越感，贬低主角
2. 主角隐忍或低调
3. 关键时刻主角展露实力/身份
4. 反派震惊、后悔、求饶
5. 周围人态度反转

**要点**：反差要大，打脸要快（不超过 3 章），不能拖。

## 2. 装逼

**触发**：主角隐匿身份进入新环境
**结构**：
1. 主角以低调姿态出现
2. 遇到挑战/危机
3. 主角漫不经心解决
4. 旁人震惊，开始猜测主角身份
5. 主角不留名离开

**要点**：装逼要自然，不能刻意；留白比直白更爽。

## 3. 逆袭

**触发**：主角处于低谷
**结构**：
1. 主角陷入绝境（修为废/被追杀/失去一切）
2. 转机出现（机缘/顿悟/贵人）
3. 主角重新崛起
4. 实力超越从前
5. 找仇人清算

**要点**：低谷不能太长（1-2 章），转机要合理。

## 4. 夺宝

**触发**：发现秘境/拍卖会/遗府
**结构**：
1. 宝物现世，各方觊觎
2. 主角以智谋/实力介入
3. 与对手周旋
4. 关键时刻夺宝
5. 宝物带来实力跃升

**要点**：夺宝过程要有智斗，不能纯靠武力。

## 5. 悟道

**触发**：主角遇到瓶颈
**结构**：
1. 主角卡在某个境界/认知
2. 经历事件触发思考
3. 顿悟，认知突破
4. 境界/实力提升
5. 视角格局打开

**要点**：悟道内容要有哲学意味，不能太水。

## 6. 收徒

**触发**：主角遇到资质好的后辈
**结构**：
1. 后辈陷入困境
2. 主角偶然相遇
3. 考验后辈心性
4. 收为弟子
5. 传承延续

**要点**：师徒情要铺垫，不能一见就收。

## 7. 灭门

**触发**：主角与某势力结仇到极点
**结构**：
1. 矛盾积累到不可调和
2. 主角实力足够
3. 周密计划
4. 一夜灭门
5. 江湖震动

**要点**：灭门要有理由，不能滥杀；过程要爽快。

## 8. 渡劫飞升

**触发**：主角修为达到顶峰
**结构**：
1. 天劫降临预兆
2. 主角准备
3. 渡劫过程（多重劫难）
4. 飞升仙界
5. 新篇章开启

**要点**：渡劫要震撼，是全书高潮。
