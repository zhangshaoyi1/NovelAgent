# 修仙题材层质量规则

> 由 quality_checker.register_genre_rules 注册。

## 规则清单

### G-01 境界推进频率
- **检查**：每 N 章（默认 10 章）必须有境界或战斗进度推进
- **严重度**：warn
- **修订提示**：长时间无境界/战斗推进，读者会感到拖沓

### G-02 战斗模板合规
- **检查**：战斗章节是否符合四段结构（试探→胶着→转折→决胜）
- **严重度**：block
- **修订提示**：战斗章节需按试探→胶着→转折→决胜四段结构组织

### G-03 智斗元素
- **检查**：战斗章节是否包含至少一项智斗元素
- **严重度**：block
- **修订提示**：战斗需包含心理博弈/环境利用/信息差/借力/以弱胜强之一

### G-04 境界战力校验
- **检查**：战斗双方境界差距是否合理，主角越级是否有金手指支持
- **严重度**：block
- **修订提示**：主角越级战斗需有金手指/秘术/法宝等合理手段

### G-05 金手指使用合规
- **检查**：金手指使用是否符合登记的成长/代价/上限
- **严重度**：block
- **修订提示**：金手指使用超出登记范围，需修订或更新登记

### G-06 爽点节奏
- **检查**：每 N 章（默认 5 章）至少一个爽点（打脸/装逼/夺宝等）
- **严重度**：warn
- **修订提示**：长时间无爽点，读者流失风险

### G-07 反派智商
- **检查**：反派是否有合理动机和智商
- **严重度**：warn
- **修订提示**：反派降智，需补充合理动机或智斗表现
