# 修仙战斗模板

> 战斗章节走此模板，强制包含智斗元素。

## 四段结构

### 1. 试探（约 20%）
- 双方互相试探实力
- 小招交锋
- 主角观察对手破绽
- **要点**：展示双方性格与战斗风格

### 2. 胶着（约 30%）
- 实力旗鼓相当
- 互有攻守
- 环境因素介入（地形/天气/旁观者）
- **要点**：制造紧张感，铺设伏笔

### 3. 转折（约 30%）
- 关键变量出现
  - 主角亮出底牌（金手指/秘术/法宝）
  - 对手露出破绽
  - 第三方介入
  - 主角以智谋翻盘
- **要点**：转折要合理，不能凭空开挂

### 4. 决胜（约 20%）
- 一击定胜负
- 战后总结
- 收获/代价展示
- **要点**：决胜要爽快，不能拖泥带水

## 智斗元素（必须包含至少一项）

- **心理博弈**：虚张声势、误导、激将
- **环境利用**：地形、天气、阵法、机关
- **信息差**：隐藏实力、保留底牌
- **借力**：利用第三方、借势
- **以弱胜强**：找到对手弱点

## 禁忌

- 流水账式动作描写（"他挥剑，对方挡住，他又挥剑"）
- 主角无脑强推
- 反派降智送人头
- 战斗过程超过 2 章不收尾（除非是大高潮）

## 境界战力校验

战斗前必须校验：
- 双方境界差距
- 主角是否有合理手段对抗高境界对手
- 金手指使用是否符合登记
- 是否越级（需金手指允许）
