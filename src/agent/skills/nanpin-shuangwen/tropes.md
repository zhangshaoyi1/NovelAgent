# 爽点套路库

> 每个套路提供模板，Agent 写作时按情境调用。可用 `/inject-genre <套路名>` 临时注入单个套路。

## 1. 扮猪吃虎
**触发**：主角落入被低估、被轻视的场合
**结构**：
- 主角主动示弱 / 隐藏身份，坐实"废物"印象
- 反派当众羞辱、立威
- 危机时刻揭露底牌（实力 / 身份 / 系统）
- 反派与围观者认知被瞬间反转
**要点**：示弱须有铺垫，揭露须有冲击力，忌中途莫名露馅

## 2. 废柴逆袭
**触发**：主角被公认为废物 / 家族弃子
**结构**：
- 长期被欺压，怨气积聚
- 偶得金手指 / 机缘
- 以小博大连胜，阶层跃迁
- 昔日轻视者跪求 / 攀附
**要点**：逆袭前给足压抑，跃迁后给足对比落差

## 3. 退婚流
**触发**：开局被强势方退婚 / 解除婚约羞辱
**结构**：
- 退婚者当众撕毁婚约、极尽嘲讽
- 主角立"他日必让尔等高攀不起"之志
- 金手指觉醒，实力狂飙
- 退婚者后悔莫及，主角云淡风轻
**要点**：经典男频开场，重点在"打脸回收"的闭环

## 4. 系统流
**触发**：主角觉醒系统面板 / 任务机制
**结构**：
- 系统发布任务，给出奖励预期
- 主角借任务链快速变强
- 系统商城 / 抽奖制造惊喜收获
- 阶段性解锁打脸新手段
**要点**：系统要有明确规则与成长感，避免无代价无脑发奖

## 5. 无敌流
**触发**：主角实力已碾压同阶
**结构**：
- 众人不知主角深浅，自不量力挑衅
- 主角从容化解，反派层层崩溃
- 旁观者逐步认知"此人不可撼动"
- 以威慑收尾，不战而屈人之兵
**要点**：爽感来自"从容碾压"，需设上限避免后期失张

## 6. 神豪流
**触发**：主角获得无限财富 / 钞能力
**结构**：
- 对手以权势 / 财富压人
- 主角以更夸张的财富反制（收购 / 天价打赏 / 砸钱）
- 物质鸿沟被瞬间抹平并反转
- 旁观者哗然，对手破产 / 臣服
**要点**：用"钞能力"碾压物质焦虑，释放现实代偿快感

## 7. 重生流
**触发**：主角带前世记忆重启人生
**结构**：
- 前世遗憾 / 仇怨被点出
- 借先知信息差抢机缘、避坑、布局
- 改变关键节点，碾压旧日对手
- 弥补遗憾，完成闭环
**要点**：信息差是核，须让"已知 vs 众人未知"形成认知差

## 8. 签到流
**触发**：主角可在特定地点 / 每日签到领奖
**结构**：
- 稳定签到积累资源 / 技能
- 关键时刻签到爆出关键奖励
- 临门一脚逆转战局
- 资源滚雪球，阶层跃迁
**要点**：强调"稳定成长 + 关键爆点"的节奏

## 9. 高手下山
**触发**：隐世高手入世 / 归来
**结构**：
- 都市 / 江湖不知主角深不可测
- 小角色挑衅，被随手镇压
- 层层引出更大势力，逐一教做人
- 身份逐步曝光，全网震惊
**要点**：反差来自"扫地僧"式深藏不露

## 10. 医圣
**触发**：主角身怀绝世医术
**结构**：
- 名医 / 权贵束手无策的重症
- 主角一招见效，打脸众医
- 救治关键人物换得人脉 / 地位
- 医道 + 武力双线打脸
**要点**：医术是金手指的一个分支，重点在"权威被颠覆"

## 11. 装逼打脸
**触发**：主角展现实力 / 身份，旁人不信
**结构**：
- 铺垫轻视：众嘲、规则不公、力量悬殊
- 期待积聚：埋信息差，反派进一步作妖
- 打脸释放：底牌揭露，认知瞬间反转
- 余波威慑：云淡风轻离场，地位反转扩散
**要点**：爽点落在"认知差被填满"的那一刻

## 12. 全网唾弃反转
**触发**：主角被舆论 / 群体针对
**结构**：
- 负面舆论铺天盖地
- 主角暗中布局，放出实锤
- 舆论一夜反转，黑子集体破防
- 主角收获声望与利益
**要点**：利用"群体偏见→真相反转"的集体打脸快感

## 13. 护妻护短
**触发**：主角在乎的人被欺
**结构**：
- 亲友受辱 / 受困
- 主角雷霆出手，不惜掀桌
- 对手付出惨痛代价
- 亲情 / 兄弟情升温，地位稳固
**要点**：以"护短"显态度，打脸带情绪厚度

## 14. 气运之子对峙
**触发**：主角遭遇"天命眷顾"型对手
**结构**：
- 对手看似处处好运、机缘不断
- 主角以布局 / 金手指拆解其气运
- 反夺机缘，气运易主
- 证明"努力 / 智计"可胜"天宠"
**要点**：把"气运"具象为可争夺的资源

## 15. 直播全能
**触发**：主角能力通过直播被见证
**结构**：
- 直播中被人质疑 / 嘲讽
- 现场秀操作，弹幕从嘲到跪
- 流量与打赏暴涨，现实地位反转
- 直播名场面成为打脸证据
**要点**：围观者（弹幕）情绪反转是放大器

## 16. 越级杀
**触发**：主角被迫高于自身阶层对敌
**结构**：
- 暴露等级劣势，众人看衰
- 以金手指 / 技巧 / 克制关系弥补
- 一击制胜，全场哗然
- 战力对标被重写
**要点**：越级须有合理解释，否则战力崩坏

## 17. 信息差碾压
**触发**：主角掌握他人未知的关键信息
**结构**：
- 对手基于错误认知步步紧逼
- 主角按已知真相反向布局
- 对手自掘坟墓，主角坐收其利
- 真相揭晓，对手崩溃
**要点**：让读者与主角同频（知底牌），让配角蒙鼓里
