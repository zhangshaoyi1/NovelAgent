## 黄金章节节奏框架（冻结字段）
- 章结构：憋屈铺垫(10%) → 期待积聚(30%) → 爽点释放(40%) → 余波威慑(15%) → 章末钩子(5%)
- 爽点密度：每章 ≥ 1 个明确爽点；每 3 章一次大爽点（打脸 / 逆袭 / 收获 / 身份反转）
- 期待感管理：章末必留钩子（悬念 / 反转 / 新底牌），禁止平淡收章
- 无虐主红线：主角吃瘪 ≤ 1 章且无重伤 / 永久损失；憋屈只为铺垫后续爽点
