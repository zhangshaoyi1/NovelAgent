# 男频爽文冲突 / 对决模板

> 对决与装逼章节走此模板，重情绪释放与信息差，而非真实战力消耗。

## 装逼打脸四段结构

### 铺垫轻视（约 20%）
- 反派 / 旁观者出场，带着偏见贬低、打压主角
- 环境压迫感：众人的嘲笑、规则的不公、力量的悬殊

### 期待积聚（约 30%）
- 主角不急着翻盘，先埋信息差（隐藏底牌 / 真实身份 / 系统提示）
- 反派进一步作妖，读者期待值拉满

### 打脸释放（约 35%）
- 底牌揭露：一招 / 一句话 / 一个身份反转让局势瞬间反转
- 围观者从嘲讽到震惊，反派从嚣张到崩溃
- 爽点落在"认知差被填满"的那一刻

### 余波威慑（约 15%）
- 主角云淡风轻离场，留下地位反转的事实
- 旁人私下传播，威慑扩散，为后续爽点铺垫

## 智斗模板
- **触发**：势力博弈 / 商战 / 规则对抗
- **结构**：设局（信息差）→ 诱导对手犯错 → 收网反杀 → 利益收割
- **要点**：胜负靠布局与信息差，不靠硬实力

## 越级杀模板
- **触发**：被迫高于自身阶层对敌
- **结构**：暴露等级劣势 → 用金手指 / 技巧 / 环境弥补 → 一击制胜 → 全场哗然
- **要点**：越级必须有合理解释（金手指 / 计谋 / 克制关系），否则战力崩坏

## 关键元素（至少包含一项）
- 信息差碾压
- 底牌揭露
- 身份反转（扮猪吃虎）
- 围观者情绪反转（嘲→惊）
- 反向打脸（本想羞辱反被羞辱）

## 禁忌
- 虐主超过一章或无故重伤 / 永久损失
- 反派无理由降智（喜剧设定除外）
- 战力对标崩坏（越级无合理解释）
- 只铺垫不释放（光憋屈不打脸）
- 章末无钩子、无余韵
