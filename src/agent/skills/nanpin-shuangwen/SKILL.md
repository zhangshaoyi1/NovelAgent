# nanpin-shuangwen Genre Skill · 男频爽文（通用爽点引擎）题材包

## 题材定位

男频爽文不是某一类设定，而是一套**读者情绪工程**：用高密度、可预期的"爽点"持续供给
阅读快感。本包不绑定具体背景（都市/玄幻/历史/末日/科幻/游戏皆可），而是提供跨题材通用的
**爽点套路库、情绪曲线框架、金手指设计准则与质量校验**，让 Agent 在任意背景下都写出"够爽"的男频文。

核心公式：**憋屈（铺垫/轻视）→ 期待（信息差/底牌）→ 释放（打脸/逆袭/收获）→ 余波（威慑/地位反转）→ 新悬念**。

## 提供能力

### 1. world.md 模板片段
见 `world-template.md`：背景选择 + 实力/阶层体系 + 金手指登记 + 黄金章节节奏框架（冻结字段）。

### 2. 爽点套路库
见 `tropes.md`：扮猪吃虎、废柴逆袭、退婚流、系统流、无敌流、神豪流、重生流、签到流、
高手下山、医圣、装逼打脸、全网唾弃反转、护妻护短、气运之子对峙、直播全能、越级杀、信息差碾压。

### 3. 术语表
见 `terms.md`：爽点、打脸、装逼、扮猪吃虎、金手指、系统、无敌流、重生、退婚流、神豪、
签到、气运、虐主、毒点、期待感、钩子、章末悬念、节奏、信息差、降智、伏笔回收。

### 4. 冲突/对决模板
见 `combat-template.md`：装逼打脸四段结构 + 智斗模板 + 越级杀模板。

### 5. 金手指模板
类型（系统/传承/重生/异能/签到）+ 成长曲线/代价/上限登记模板。

### 6. 题材层质量规则
见 `quality-rules.md`：爽点密度、打脸节奏、无虐主、金手指自洽、反派智商、期待感管理、
开篇抓人、装逼分寸、战力对标、节奏不拖、信息差运用、情绪曲线。

## 加载方式

题材包由主 Agent 在 M1 配置阶段自动加载（用户选择本题材时）。
无需手动 /load-skill。写作中可用 `/inject-genre <套路名>` 临时注入单个套路模板（如 `/inject-genre 扮猪吃虎`）。
