# 题材层质量规则

> 由 quality_checker.register_genre_rules 注册。

## 规则清单

### G-01 异能自洽
- **检查**：异能效果与等级匹配，不随意升级
- **严重度**：block
- **修订提示**：越级需合理手段

### G-02 都市感
- **检查**：场景/职业/矛盾有现代都市真实感
- **严重度**：warn
- **修订提示**：避免架空失根

### G-03 爽点节奏
- **检查**：每 N 章至少一个打脸/逆袭爽点
- **严重度**：warn
- **修订提示**：长时间压抑流失读者

### G-04 反套路
- **检查**：避免千篇一律龙傲天
- **严重度**：warn
- **修订提示**：加入反预期反转

### G-05 身份张力
- **检查**：双重身份周旋有危机感
- **严重度**：warn
- **修订提示**：身份戏不可太平

### G-06 代价合理
- **检查**：金手指使用符合登记代价
- **严重度**：block
- **修订提示**：无代价金手指破坏平衡

### G-07 战力对标
- **检查**：异能等级与凡人/热武器对标清晰
- **严重度**：block
- **修订提示**：战力崩坏读者出戏

### G-08 配角智商
- **检查**：反派/组织有逻辑与手段
- **严重度**：warn
- **修订提示**：避免反派降智
