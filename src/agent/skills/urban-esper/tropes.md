# 爽点套路库

> 每个套路提供模板，Agent 写作时按情境调用。

## 1. 异能觉醒

**触发**：主角遭变故/奇遇
**结构**：
- 压抑的平凡生活
- 突变触发觉醒
- 试探能力边界
- 初次运用惊艳旁人
**要点**：觉醒要有反差，从弱到惊艳

## 2. 打脸装逼

**触发**：被轻视/嘲讽
**结构**：
- 对方炫耀
- 主角低调回应
- 关键时刻展露实力
- 围观者反转态度
**要点**：反差大、落败干脆

## 3. 捡漏鉴宝

**触发**：古玩/地摊偶遇
**结构**：
- 以异能/眼力识破真伪
- 低价收入宝物
- 专家打脸
- 价值兑现
**要点**：鉴宝过程要有专业细节

## 4. 隐秘身份

**触发**：被局/组织注意
**结构**：
- 双重身份周旋
- 暴露边缘试探
- 以智化解危机
- 身份升华
**要点**：身份戏要有张有弛

## 5. 都市奇遇

**触发**：偶得传承/系统
**结构**：
- 获得金手指
- 摸索用法
- 首秀见效
- 卷入更大漩涡
**要点**：奇遇需有代价或考验

## 6. 校园/职场逆袭

**触发**：被排挤/埋没
**结构**：
- 暗中积累
- 关键场合证明
- 打脸上位者
- 格局打开
**要点**：逆袭要合理，不无脑
