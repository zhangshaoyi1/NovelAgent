# 爽点套路库

> 每个套路提供模板，Agent 写作时按情境调用。

## 1. 渡劫保险

**触发**：主角面临雷劫
**结构**：
- 测算劫数等级
- 选购保险套餐
- 雷劫中理赔兜底
- 反套路脱险
**要点**：现代设定要服务爽点，不喧宾夺主

## 2. 宗门KPI

**触发**：年度考核压力
**结构**：
- 指标压顶
- 以现代管理破局
- 超额完成打脸长老
- 晋升核心弟子
**要点**：职场梗要自然融入修真

## 3. 灵石贷款

**触发**：资源短缺
**结构**：
- 申请灵脉按揭
- 用未来收益填坑
- 反被追债逼出底牌
- 逆风翻盘
**要点**：借贷要有真实压力与代价

## 4. 赛博悟道

**触发**：瓶颈借数据突破
**结构**：
- 用量化思维解析功法
- 找到最优解
- 顿悟升级
- 格局打开
**要点**：现代×修真融合需自洽

## 5. 修真直播

**触发**：流量时代扬名
**结构**：
- 开播展示神通
- 吸粉打赏灵石
- 翻车危机
- 逆袭封神
**要点**：直播梗服务传播爽感

## 6. 系统修仙

**触发**：绑定现代系统
**结构**：
- 系统发布任务
- 奖励反哺修为
- 卡BUG刷分
- 碾压同辈
**要点**：系统要有规则与限制
