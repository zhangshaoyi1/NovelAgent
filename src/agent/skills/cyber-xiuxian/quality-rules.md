# 题材层质量规则

> 由 quality_checker.register_genre_rules 注册。

## 规则清单

### G-01 设定新颖
- **检查**：现代设定服务爽点且不喧宾夺主
- **严重度**：warn
- **修订提示**：避免玩梗过度冲淡修真

### G-02 融合自洽
- **检查**：科技×修真不矛盾，逻辑可解释
- **严重度**：block
- **修订提示**：融合点需合理

### G-03 境界推进
- **检查**：每 N 章有境界/地位推进
- **严重度**：warn
- **修订提示**：长期无推进拖沓

### G-04 战斗模板
- **检查**：战斗章节走修真对决结构
- **严重度**：block
- **修订提示**：战斗需起手→交锋→变招→决胜

### G-05 金手指合规
- **检查**：系统/现代知识使用符合登记
- **严重度**：block
- **修订提示**：超出登记需补登

### G-06 战力校验
- **检查**：越级有金手指/智谋支持
- **严重度**：block
- **修订提示**：越级需合理手段

### G-07 职场梗节制
- **检查**：KPI/贷款梗适度，不滥
- **严重度**：warn
- **修订提示**：梗过多变轻浮

### G-08 侠义精神
- **检查**：主角行为有底线
- **严重度**：warn
- **修订提示**：避免无义失格
