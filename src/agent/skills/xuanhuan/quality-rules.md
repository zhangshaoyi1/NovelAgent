# 玄幻题材层质量规则

> 由 quality_checker.register_genre_rules 注册。

## 规则清单

### G-01 等阶推进频率
- **检查**：每 N 章（默认 10 章）必须有等阶或战力推进
- **严重度**：warn
- **修订提示**：长时间无升级/战力推进，读者会感到拖沓

### G-02 战斗模板合规
- **检查**：战斗章节是否符合四段结构（蓄势→对轰→爆种→定局）
- **严重度**：block
- **修订提示**：战斗章节需按蓄势→对轰→爆种→定局四段结构组织

### G-03 渲染元素
- **检查**：战斗章节是否包含至少两项渲染元素（异象/旁观者/招式命名/数据对比/代价可见）
- **严重度**：warn
- **修订提示**：战斗缺乏渲染，临场感不足

### G-04 等阶战力校验
- **检查**：战斗双方等阶差距是否合理，主角越级是否有金手指支持
- **严重度**：block
- **修订提示**：主角越级战斗需有血脉/神器/秘术等合理手段

### G-05 金手指使用合规
- **检查**：金手指使用是否符合登记的成长/代价/上限
- **严重度**：block
- **修订提示**：金手指使用超出登记范围，需修订或更新登记

### G-06 爽点节奏
- **检查**：每 N 章（默认 5 章）至少一个爽点（打脸/夺魁/觉醒/夺宝等）
- **严重度**：warn
- **修订提示**：长时间无爽点，读者流失风险

### G-07 换图收束
- **检查**：跨地图/跨境界大节奏点前，旧地图的仇怨与羁绊是否收束
- **严重度**：warn
- **修订提示**：换图前遗留伏笔需回收或显式挂起，禁止烂尾式弃线
