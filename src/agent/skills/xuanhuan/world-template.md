# 玄幻等阶体系模板

> 此片段在 M1 配置阶段注入 world.md，并标记为冻结字段。

## 等阶体系（冻结字段，修改需解冻命令）

| 等阶 | 阶段 | 战力区间 | 社会地位 |
|---|---|---|---|
| 淬体境 | 入门 | 1-10 | 普通武者 |
| 聚气境 | 入门 | 10-50 | 一城之才 |
| 通脉境 | 中坚 | 50-200 | 家族核心 |
| 凝元境 | 中坚 | 200-500 | 一方强者 |
| 王境 | 高阶 | 500-2000 | 一国翘楚 |
| 皇境 | 高阶 | 2000-5000 | 一域霸主 |
| 帝境 | 顶峰 | 5000-20000 | 大陆巅峰 |
| 圣境 | 顶峰 | 20000-50000 | 万年一遇 |
| 神境 | 终极 | 50000+ | 传说中的存在 |

> 可替换命名：斗气体系（斗者→斗宗→斗帝）/ 源力体系 / 星力体系——保留等阶结构，换命名皮肤即可。

## 力量体系

- **根基**：斗气 / 源力 / 武魂，觉醒品质分凡、玄、地、天四品
- **功法武技**：分黄、玄、地、天四阶，每阶分初中高三级
- **血脉**：龙、凤、荒古凶兽等上古血脉，浓度决定觉醒上限
- **神通**：高阶觉醒的天赋异能，每人至多一项

## 势力框架

- 边陲小城 / 家族（主舞台起点）
- 宗门与学院（试炼与升级主场景）
- 王朝 / 帝国（中盘政治博弈）
- 圣地 / 上古遗迹（高阶资源与传承）
- 域外天魔 / 异族（终极威胁）
