# 玄幻战斗模板

> 战斗章节走此模板，注重气氛渲染与招式对撞。

## 四段结构

### 1. 蓄势（约 20%）
- 对峙与言语交锋，立赌约/立仇恨
- 双方亮出底牌的表象（武魂/神兵/气势）
- 旁观者视角铺垫期待
- **要点**：战斗前读者必须知道"主角赢面在哪、险在哪"

### 2. 对轰（约 30%）
- 招式对撞，拳拳到肉
- 双方底牌逐层加码
- 场地破坏、异象渲染
- **要点**：对轰要有回合感，不能一招定胜负（除非碾压局）

### 3. 爆种（约 30%）
- 关键变量出现：
  - 主角血脉/神器异动
  - 秘术爆发（付出代价）
  - 对手狂傲露出破绽
  - 借地利/第三方之力
- **要点**：爆种必须对应已铺垫的底牌或已登记的金手指

### 4. 定局（约 20%）
- 一击定胜负，慢镜头收尾
- 战果清点（奖励/代价/名声）
- 败者下场与旁观者反应
- **要点**：定局要爽快，同时留下下一段剧情的钩子

## 渲染元素（每场战斗至少两项）

- **异象**：天地变色、异火焚空、神兽虚影
- **旁观者反应**：惊呼、倒吸凉气、势力代表交头接耳
- **招式命名**：招式有名字，喊出来打
- **数据对比**：等阶差、血脉浓度、兵器品级
- **代价可见**：秘术的反噬当场体现

## 禁忌

- 招式描写重复（全书反复"一拳轰出"）
- 主角无脑碾压无险情
- 反派话多送死、临死才爆猛料
- 普通战斗超过 2 章不收尾（大高潮除外）

## 等阶战力校验

战斗前必须校验：
- 双方等阶差距
- 主角越级是否有血脉/神器/秘术支持
- 金手指使用是否符合登记
- 秘术代价是否结算
