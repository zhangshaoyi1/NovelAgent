# 玄幻爽点套路库

> 每个套路提供模板，Agent 写作时按情境调用。

## 1. 打脸

**触发**：主角被嘲讽废柴/被退婚/被欺辱
**结构**：
1. 反派当众贬低主角，立赌约
2. 主角淡然接受，旁人冷眼旁观
3. 比试/对决中主角一鸣惊人
4. 反派难以置信、众哗然
5. 主角淡定离场，名声初显

**要点**：废柴标签贴得越狠，打脸越响；打脸不超过 3 章。

## 2. 试炼夺魁

**触发**：学院大比/宗门选拔/秘境排名
**结构**：
1. 试炼规则公布，强敌环伺
2. 主角低调晋级，锋芒渐露
3. 强敌阻拦，主角连破纪录
4. 决战强敌，问鼎魁首
5. 奖励到手 + 大人物注意

**要点**：试炼是升级与扬名的复合爽点，奖励要具体。

## 3. 血脉/武魂觉醒

**触发**：主角濒死/瓶颈/大机缘
**结构**：
1. 主角陷入绝境
2. 血脉/武魂异动，觉醒征兆
3. 觉醒过程（痛苦+异象）
4. 实力暴涨，压轴翻盘
5. 觉醒来历留下伏笔

**要点**：觉醒异象要渲染，来历埋线供后期展开。

## 4. 夺宝

**触发**：遗迹出世/拍卖会/宗门宝库
**结构**：
1. 宝物现世，各方汇聚
2. 主角凭机缘/眼力占先
3. 与强者周旋周旋
4. 关键时刻夺宝走人
5. 宝物推动等阶跃升

**要点**：夺宝要有惊无险中有智斗，不能纯靠硬抢。

## 5. 扬名立万

**触发**：主角战绩传开
**结构**：
1. 战绩经旁观者/说书人扩散
2. 各方势力反应（招揽/忌惮/追杀）
3. 主角获得名号
4. 昔日轻视者态度反转
5. 更大舞台向他敞开

**要点**：扬名靠第三方视角渲染，比自述更有爽感。

## 6. 护短

**触发**：主角亲友被欺
**结构**：
1. 反派欺压主角亲友
2. 亲友隐忍或重伤
3. 主角赶到，气势全开
4. 强势碾压，立威立规
5. 亲友团体凝聚力提升

**要点**：护短是团队情感爽点，铺垫受害过程要充分。

## 7. 宗门覆灭 / 血仇清算

**触发**：主角与敌对势力仇怨累积到顶点
**结构**：
1. 旧仇引燃，证据坐实
2. 主角实力到位，布局周密
3. 雷霆一击
4. 仇敌覆灭，天下震动
5. 遗留线索引向幕后黑手

**要点**：复仇要有理有据，节奏干脆。

## 8. 破界升维

**触发**：主角等阶到达当前世界顶峰
**结构**：
1. 当前世界天花板显现
2. 上界/新大陆的入口与资格之争
3. 主角力压群雄取得资格
4. 飞升/穿越界膜
5. 新篇章开启，旧日荣光归零再爬

**要点**：换图是玄幻的大节奏点，旧世界的羁绊要收束。
