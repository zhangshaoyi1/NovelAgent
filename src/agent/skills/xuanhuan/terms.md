# 玄幻术语表

## 根基与力量
- **斗气/源力**：修炼所得能量，等阶的量化基础
- **武魂/血脉**：觉醒的天赋本源，决定成长上限
- **神通**：高阶觉醒的天赋异能，一生至多一项
- **领域**：王境以上展开的规则力场

## 功法武技
- **黄阶/玄阶/地阶/天阶**：功法四阶，每阶分初中高三级
- **身法**：位移类武技（瞬影、游龙等）
- **秘术**：以血/寿元为代价的爆发手段

## 神兵丹药
- **凡兵/灵兵/宝兵/神兵**：兵器四品，神兵有器灵
- **淬体丹/聚元丹/破境丹**：升级辅助线
- **疗伤圣药/涅槃液**：重伤保命线

## 组织地位
- **家族**：起点舞台，族老/家主
- **学院**：外院/内院/核心弟子，导师制
- **宗门**：外门/内门/真传，长老/太上
- **圣地**：大陆顶端势力，圣主坐镇
- **王朝**：世俗皇权，与武道势力共治

## 秘境试炼
- **小秘境**：低阶资源，学院/宗门内部
- **上古遗迹**：传承+重宝，多方争夺
- **域外战场**：人族与异族的绞肉磨盘
- **试炼塔/登天路**：等阶排名与奖励体系

## 其他
- **等阶压制**：大境界之间的战力鸿沟
- **越级挑战**：需金手指/秘术支持
- **闭关**：突破前的封闭修炼
- **飞升**：破界前往上界
