# 题材层质量规则

> 由 quality_checker.register_genre_rules 注册。

## 规则清单

### G-01 年代真实
- **检查**：物件/制度/口吻符合年代
- **严重度**：block
- **修订提示**：现代词穿帮出戏

### G-02 致富逻辑
- **检查**：财富积累有路径不空降
- **严重度**：block
- **修订提示**：无脑暴富虚假

### G-03 不狗血
- **检查**：冲突生活化非撕逼
- **严重度**：warn
- **修订提示**：过度宅斗失温情

### G-04 温情自然
- **检查**：亲情/邻里有来有回
- **严重度**：warn
- **修订提示**：强行煽情

### G-05 手艺专业
- **检查**：非遗/厨艺描写到位
- **严重度**：warn
- **修订提示**：外行描写

### G-06 节奏舒缓
- **检查**：张弛有度，不全程平淡
- **严重度**：warn
- **修订提示**：无起伏乏味

### G-07 机遇贴合
- **检查**：时代机遇符合历史
- **严重度**：warn
- **修订提示**：穿越式金手指

### G-08 成长可见
- **检查**：家庭/产业有进阶
- **严重度**：warn
- **修订提示**：一成不变
