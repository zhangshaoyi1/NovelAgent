# 爽点套路库

> 每个套路提供模板，Agent 写作时按情境调用。

## 1. 重生回到年代

**触发**：主角魂穿/重回
**结构**：
- 确认时代
- 盘点资源
- 定小目标
- 低调起步
**要点**：年代感要真实

## 2. 种田致富

**触发**：经营田地/手艺
**结构**：
- 选对作物/手艺
- 精耕细作
- 卖出好价
- 积蓄增厚
**要点**：致富逻辑要自洽

## 3. 手艺变现

**触发**：展示非遗/厨艺
**结构**：
- 以技艺惊艳
- 接单变现
- 口碑扩散
- 产业雏形
**要点**：手艺细节要专业

## 4. 养娃日常

**触发**：抚育子女
**结构**：
- 陪伴成长
- 教育用心
- 化解矛盾
- 温情落点
**要点**：养娃要自然不煽情

## 5. 邻里温情

**触发**：互助事件
**结构**：
- 帮邻解困
- 换得人情
- 共渡难关
- 口碑积累
**要点**：温情要有来有回

## 6. 时代机遇

**触发**：政策/市场变化
**结构**：
- 提前布局
- 踩中红利
- 规模扩张
- 阶层跃迁
**要点**：机遇要贴合历史背景
