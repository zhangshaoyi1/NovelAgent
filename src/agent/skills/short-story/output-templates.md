# 短篇拆文输出模板

> 拆文输出时加载。先看决策路由选 Stage，再按模板填写。

## 拆解维度与必填项

| 维度 | 必填内容 |
|------|----------|
| 故事核 | 设定 + 主题 + 核心行动 + 一句话合并 |
| 结构 | 4-6 段（必须含开端/发展/高潮/结局），每段有字数范围、占比与功能 |
| 情节节点 | 每 200-300 字一个节点，每节 3-8 个；每节点有情绪标记（类型 + 强度 -9~+9） |
| 情感曲线 | ≥max(5, 节数) 节点，含字数位置、强度、方向、钩子类型 |
| 爆点分析 | 6 维度：铺垫/积累/延迟/爆发点/余波/印象 |
| 反转设计 | 反转类型 + 铺垫线索（≥2 条）+ 误导方向 + 真相揭示 + 时机 |
| 写作手法 | ≥5 项维度：POV/对话/时间/信息/其他 |
| 人物 | 二维分类（叙事角色 + 行动角色）+ 功能标签 + 内在矛盾 + 弧线 |
| 开头 | 前 3 句引用 + 前50/100字检查 + 钩子类型 + 情绪强度(1-10) |
| 结尾 | 结尾类型 + 情绪落点 + 余韵 + 收束完整性 + 情绪强度(1-10) |
| 综合评估 | 五维评分(1-5) + 爆点性 + 话题性 + 共鸣(≥3层) + 可复用结构(≥3条) + 节奏速报 |

## 短篇结构速查库

| 结构 | 特点 | 适合情绪 |
|------|------|----------|
| 三幕反转式 | 铺垫→升级→反转 | 震惊、意难平 |
| 双线交叉式 | 明线暗线交替推进 | 悬疑、真相揭晓 |
| 时间跳跃式 | 过去/现在穿插 | 遗憾、成长 |
| 套娃反转式 | 多层反转嵌套 | 惊讶、烧脑 |
| 对话驱动式 | 通过对话推进叙事 | 虐恋、人际冲突 |
| 独白式 | 第一人称内心独白 | 治愈、自省 |
| 重生反常式 | 重生后做相反的事→对手自乱 | 爽、解气 |
| 灵魂旁观式 | 死后灵魂看世界→揭露真相 | 意难平、愤怒 |
| 双重生博弈式 | 两人都重生→信息战 | 紧张、痛快 |
| 隐忍布局式 | 表面顺从暗中布局→反攻 | 压抑→极致释放 |
| 非人视角式 | 鬼/系统/灵魂看人间 | 新奇、恐怖、爽 |
| 成长救赎式 | 苦难中被人拉一把→自我救赎→约定未来 | 温暖、心酸、治愈 |
| 舆论反转式 | 舆论多次反转→证据反击→真相大白 | 爽、解气、震惊 |
| 冷面复仇式 | 冷静主角收集证据→果断出手→全身而退 | 爽、痛快、满足 |
| 倒计时告别式 | 明确时限的告别→倒计时推进→最终诀别 | 心酸、意难平、通透 |

## 质量门控必填字段

拆解完成前逐项检查，缺一即不完整：

- [ ] 故事核已提取（一句话核心梗）
- [ ] 结构划分 4-6 段（必须含开端/发展/高潮/结局）
- [ ] 情感曲线节点 ≥5，每节点有字数位置、强度与方向、钩子类型
- [ ] 爆点分析 6 维度齐全（铺垫/积累/延迟/爆发点/余波/印象）
- [ ] 反转铺垫线索 ≥2 条；无传统反转时注明
- [ ] 写作手法分析 ≥5 项维度
- [ ] 所有有名人物已提取，有二维分类
- [ ] 前 3 句引用 + 前50/100字检查已完成
- [ ] 结尾类型与情绪落点已说明；钩子回收状态已标注
- [ ] 五维评分每项有具体说明
- [ ] 共鸣分析 ≥3 层；可复用结构 ≥3 条（每条含适用场景）
- [ ] 节奏速报已包含
