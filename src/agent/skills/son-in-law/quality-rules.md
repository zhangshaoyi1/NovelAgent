# 题材层质量规则

> 由 quality_checker.register_genre_rules 注册。

## 规则清单

### G-01 反差爽点
- **检查**：隐忍到爆发的反差足
- **严重度**：warn
- **修订提示**：受辱过长读者弃书

### G-02 身份揭示节奏
- **检查**：实力/身份分层释放
- **严重度**：warn
- **修订提示**：一次性摊牌乏味

### G-03 不无脑碾压
- **检查**：打脸靠铺垫与手段
- **严重度**：block
- **修订提示**：纯战力碾压出戏

### G-04 护妻有度
- **检查**：情感线服务人设不喧宾
- **严重度**：warn
- **修订提示**：过度甜腻失衡

### G-05 战力校验
- **检查**：战神级有对应代价与边界
- **严重度**：block
- **修订提示**：无敌破坏张力

### G-06 医道专业
- **检查**：圣医情节符合基本医理
- **严重度**：warn
- **修订提示**：外行描写掉价

### G-07 配角智商
- **检查**：豪门有手段不降智
- **严重度**：warn
- **修订提示**：反派送人头

### G-08 爽点节奏
- **检查**：每 N 章至少一打脸爽点
- **严重度**：warn
- **修订提示**：压抑流失
