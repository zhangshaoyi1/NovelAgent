# 游戏电竞术语表

## 操作与意识
- **手速/APM**：每分钟操作数，操作流的基础指标
- **预判**：提前判断对手走位/技能
- **走位**：位移与站位技术
- **意识**：地图信息/局势/对手心理的综合判断
- **微操**：多单位/多技能的精细控制
- **极限反杀**：濒死翻盘，名场面类型

## 对局与战术
- **BP/禁选**：电竞局前的英雄/阵容博弈
- **版本强势**：当前版本最有效的英雄/战术
- **运营**：资源换算与节奏控制
- **开团/接团**：团战发起与应对
- **分推/抱团**：兵线战术
- **心态局**：心理博弈主导的对局

## 副本与装备（网游向）
- **开荒**：首次攻克副本
- **首杀/首通**：全服第一，自带公告曝光
- **CD**：副本次数限制
- **极品装备**：高品质/稀有词条装备
- **拍卖行/摆摊**：交易系统
- **公会**：玩家组织，团本与领地战主体

## 赛事体系
- **城市赛→联赛→洲际赛→世界赛**：实力阶梯
- **小组赛/淘汰赛/决胜局**：赛制节点
- **退役/转会/青训**：选手生命周期
- **解说/复盘**：赛后分析，上帝视角爽点载体

## 现实生态
- **直播**：人气与收入来源，观众弹幕是反应板
- **战队/俱乐部**：职业组织，经理/教练/分析师
- **黑子/黑粉**：舆论阻力源
- **代言/身价**：商业价值线
