# 游戏电竞世界观模板

> 此片段在 M1 配置阶段注入 world.md，并标记为冻结字段。

## 游戏世界设定（冻结字段，修改需解冻命令）

### 方案 A：虚拟网游/全息游戏
- **游戏框架**：职业体系（战士/法师/刺客/牧师等）、等级上限、副本与野图
- **核心资源**：装备（白/绿/蓝/紫/橙品质梯度）、技能书、金币与现实货币兑换
- **特色机制**：全息体感/第一滴血/首杀首通排名

### 方案 B：硬核电竞（类 MOBA/FPS/格斗）
- **赛事体系**：城市赛→职业联赛→洲际赛→世界赛（实力阶梯）
- **版本环境**：版本强势英雄/战术/禁选规则（版本理解是强队分水岭）
- **俱乐部生态**：青训/首发/替补/转会/直播合约

## 实力阶梯（冻结字段，修改需解冻命令）

| 梯队 | 水平 | 对应舞台 |
|---|---|---|
| 萌新 | 刚入坑 | 新手村 |
| 高手 | 服务器前列 | 野队/公会主力 |
| 大神 | 全服排行 | 直播间/豪门邀约 |
| 职业 | 联赛选手 | 职业联赛 |
| 顶级 | 联赛明星 | 洲际赛 |
| 传奇 | 世界之巅 | 世界赛决赛 |

## 双线框架

- **游戏内线**：升级/装备/排名/对局，爽点主供给
- **现实线**：生活压力/战队经营/队友羁绊/对手恩怨，情感与动机供给
- **两线配比**：默认 6:4 偏游戏线，赛事期间可到 8:2
