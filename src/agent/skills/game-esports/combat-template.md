# 游戏电竞对局模板

> 对局（个人赛/排位/团战）走此模板，强制写清胜负手。

## 四段结构

### 1. 开局（约 20%）
- 对局背景与双方阵容/状态
- 赛前博弈（BP/心理战/舆论压力）
- **要点**：读者需提前知道双方的底牌与短板

### 2. 相持（约 30%）
- 常规博弈，互有攻防
- 小规模交锋试探（换血/野区遭遇/资源争夺）
- **要点**：展示双方风格差异，为主角的突破口做铺垫

### 3. 胜负手（约 30%）
- 关键决策或操作出现：
  - 预判对手战术并反制
  - 极限操作完成以少换多
  - 版本理解差（新套路/冷门解）
  - 心理博弈（钓鱼/引诱开团）
- **要点**：胜负手必须具体可复盘（操作细节/决策逻辑），禁止靠对手白给

### 4. 收尾（约 20%）
- 优势扩大到终结比赛
- 数据面板/回放确认
- 观众/解说/对手反应
- **要点**：收尾要有情绪出口（弹幕爆炸/对手复盘服气）

## 描写元素（每场对局至少两项）

- **镜头感**：关键时刻慢镜头，操作逐帧拆解
- **解说视角**：第三方实时解说承载信息与情绪
- **观众反应**：弹幕/现场欢呼，情绪放大器
- **数据对比**：经济/输出/承伤曲线
- **对手视角**：强敌的心理崩塌或复盘钦佩

## 禁忌

- 胜负归因于对手失误而非主角发挥
- 操作描写空泛（"一套连招秒了"无细节）
- 对局节奏拖沓，一场比赛超过 3 章（决赛除外）
- 现实线与游戏线比例失衡（连续 5 章纯游戏或纯日常）

## 实力一致性校验

对局前必须校验：
- 双方梯队差距与主角越级挑战的依据
- 金手指使用是否符合登记
- 装备/英雄/战术是否为前文已铺垫
- 版本规则是否与设定一致
