# 游戏电竞爽点套路库

> 每个套路提供模板，Agent 写作时按情境调用。

## 1. 一鸣惊人

**触发**：无名新人进入高手局/大赛
**结构**：
1. 被轻视（路人/职业选手的傲慢）
2. 对局开始，常规压制
3. 主角反打，操作细节拉满
4. 对手心态崩盘，比分逆转
5. 观众/解说炸锅，一战成名

**要点**：反打要有具体操作细节（走位/时机/预判），不能只写结果。

## 2. 捡漏爆装 / 首杀首通

**触发**：新副本/隐藏BOSS/BUG级打法
**结构**：
1. 全服卡关的副本/任务
2. 主角发现被忽视的机制
3. 组队开荒，险象环生
4. 首通爆出极品装备
5. 名字登上全服公告

**要点**：机制发现要合理（职业特长/细心观察），不能纯运气。

## 3. 天梯登顶

**触发**：排位/天梯冲分
**结构**：
1. 冲分目标公布（赌约/恩怨）
2. 连胜与卡分波折交替
3. 撞车宿敌/职业选手
4. 巅峰对局，操作与意识全开
5. 登顶，全服震动

**要点**：冲分途中要有挫折（连败/状态低谷），登顶才有分量。

## 4. 赛事逆转

**触发**：大赛淘汰赛，比分落后
**结构**：
1. 大比分落后，队内气氛凝重
2. 暂停/换人/战术调整
3. 逐局追分，每局都有名场面
4. 决胜局，胜负手清晰
5. 逆转夺冠，情绪总爆发

**要点**：逆转由具体调整驱动（战术/心态/版本理解），不是打鸡血。

## 5. 豪门邀约 / 身价暴涨

**触发**：主角表现被职业圈注意
**结构**：
1. 比赛视频流传
2. 战队/俱乐部接触，报价竞逐
3. 身边人态度变化（家人/朋友/旧敌）
4. 主角权衡选择
5. 进入更高舞台

**要点**：报价与合约细节要具体，选择要符合主角动机。

## 6. 打脸黑子

**触发**：被质疑/被嘲讽（Age太大/手速不行/外挂嫌疑）
**结构**：
1. 舆论发酵，黑子狂欢
2. 主角不回应，闷头准备
3. 公开对局/直播实测
4. 表现碾压质疑
5. 舆论反转，黑子哑火

**要点**：质疑要有根有据，反转靠实力不靠嘴。

## 7. 队伍经营 / 磨合成型

**触发**：组队/接手弱队
**结构**：
1. 队员各有短板与心结
2. 主角以实力与人格凝聚队伍
3. 针对性补强（战术/训练/引援）
4. 从连败到爆冷赢强队
5. 战队气质蜕变

**要点**：每个队员的短板与成长弧线要分别兑现。

## 8. 登顶世界 / 卫冕传奇

**触发**：世界赛决赛
**结构**：
1. 决赛宿敌对位（多年恩怨收束）
2. BP/战术博弈层
3. 局内操作与意识巅峰对决
4. 夺冠瞬间，全场沸腾
5. 职业生涯总结与传承

**要点**：决赛必须收束全书恩怨线与情感线，操作描写要全书最高规格。
