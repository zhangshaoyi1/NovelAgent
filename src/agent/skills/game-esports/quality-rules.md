# 游戏电竞题材层质量规则

> 由 quality_checker.register_genre_rules 注册。

## 规则清单

### G-01 对局胜负手校验
- **检查**：关键对局是否有清晰的胜负手（操作/意识/战术），禁止对手白给
- **严重度**：block
- **修订提示**：胜利需由主角的具体发挥驱动，补写胜负手细节

### G-02 成长推进频率
- **检查**：每 N 章（默认 10 章）必须有等级/装备/排名/赛事层级推进
- **严重度**：warn
- **修订提示**：长期无成长推进，读者会失去追读动力

### G-03 对局模板合规
- **检查**：对局章节是否符合四段结构（开局→相持→胜负手→收尾）
- **严重度**：block
- **修订提示**：对局需按开局→相持→胜负手→收尾结构组织

### G-04 版本/规则一致性
- **检查**：英雄强度/装备数值/赛制规则是否与设定一致
- **严重度**：block
- **修订提示**：前后规则矛盾会击穿游戏设定的可信度

### G-05 操作描写细节度
- **检查**：名场面是否具备操作细节（逐帧/走位/时机），禁止空泛形容
- **严重度**：warn
- **修订提示**："一套连招秒了"式空泛描写需拆解为具体操作

### G-06 双线平衡
- **检查**：游戏线与现实线的配比是否失衡（连续 5 章纯单线）
- **严重度**：warn
- **修订提示**：游戏爽点与现实情感需交替供给

### G-07 梯队压制合理性
- **检查**：主角越级挑战是否有金手指/版本理解等合理依据
- **严重度**：block
- **修订提示**：越级取胜需符合实力阶梯设定
