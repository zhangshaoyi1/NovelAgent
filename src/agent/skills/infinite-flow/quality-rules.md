# 题材层质量规则

> 由 quality_checker.register_genre_rules 注册。

## 规则清单

### G-01 规则自洽
- **检查**：副本规则内部无矛盾，破局方式符合规则文字
- **严重度**：block
- **修订提示**：规则需可被文本验证，避免『作者强行设定』

### G-02 逻辑闭环
- **检查**：谜题解答有前因，不靠天降外援
- **严重度**：block
- **修订提示**：破局线索须在前文铺垫

### G-03 智斗优先
- **检查**：危机主要靠分析/布局化解，而非战力
- **严重度**：block
- **修订提示**：胜负关键写明逻辑链

### G-04 污染管理
- **检查**：污染值增长与锚点抵消有节奏
- **严重度**：warn
- **修订提示**：长时间无污染波动会失去悬疑张力

### G-05 队友智商
- **检查**：背刺/合作动机合理
- **严重度**：warn
- **修订提示**：避免队友无理由降智送人头

### G-06 身份悬念
- **检查**：非人/伪装线索渐进释放
- **严重度**：warn
- **修订提示**：忌过早摊牌失去悬疑

### G-07 爽点节奏
- **检查**：每 N 章至少一个破局/反杀爽点
- **严重度**：warn
- **修订提示**：长时间压抑无释放会流失读者

### G-08 战力不崩
- **检查**：异常实体强度与主角成长匹配
- **严重度**：block
- **修订提示**：越级需合理手段支持
