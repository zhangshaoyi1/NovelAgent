# 题材体系模板

> 此片段在 M1 配置阶段注入 world.md，并标记为冻结字段。

## 规则与副本体系（冻结字段）
- 副本：独立规则空间，进入即受规则约束，破局或死亡方可离开
- 规则等级：白/绿/蓝/紫/红，越高越诡异危险
- 污染值：接触异常事物累积，超阈值理智崩溃
- 锚点：维持自我认知的关键物品/记忆，可抵消污染

## 能力体系
- 序列/职业：如『侦探』『医生』『战士』，决定初始技能
- 天赋：被动增益（观察/抗污染/近战），通过副本奖励升级
- 收容物：可携带的异常物品，有副作用

## 阵营框架
- 观测者：更高维存在，发布任务与规则
- 玩家阵营：临时组队，利益为先易背刺
- 异常实体：规则守护者/污染化身

## 金手指登记模板
- 金手指名称：<> 类型：序列天赋|收容物|规则漏洞
- 成长曲线：<随副本通关与奖励如何成长>
- 代价：<使用代价/污染/限制>
- 上限：<不能突破的能力上限>
