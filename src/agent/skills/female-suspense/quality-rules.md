# 题材层质量规则

> 由 quality_checker.register_genre_rules 注册。

## 规则清单

### G-01 逻辑严谨
- **检查**：推理链无漏洞，证据可支撑结论
- **严重度**：block
- **修订提示**：结论需前文证据支撑

### G-02 无降智
- **检查**：反派/警察有智商与手段
- **严重度**：block
- **修订提示**：避免全员降智送人头

### G-03 女性视角
- **检查**：以女主专业与独立驱动，不恋爱脑
- **严重度**：warn
- **修订提示**：避免无CP却暗恋套路

### G-04 反转合理
- **检查**：反转有铺垫不突兀
- **严重度**：block
- **修订提示**：反转需前文埋线

### G-05 节奏张弛
- **检查**：铺垫与高压交替
- **严重度**：warn
- **修订提示**：全程平淡失张力

### G-06 伏笔回收
- **检查**：线索最终回收闭合
- **严重度**：warn
- **修订提示**：留未解红线

### G-07 专业感
- **检查**：探案流程符合职业逻辑
- **严重度**：warn
- **修订提示**：避免外行描写

### G-08 代价真实
- **检查**：女主承担风险与创伤
- **严重度**：warn
- **修订提示**：无代价神挡杀神
