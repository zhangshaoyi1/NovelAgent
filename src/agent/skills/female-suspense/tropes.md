# 爽点套路库

> 每个套路提供模板，Agent 写作时按情境调用。

## 1. 谜案开场

**触发**：离奇案件出现
**结构**：
- 抛出非常规现场
- 女主被卷入
- 初步勘察
- 锁定疑点
**要点**：开场要有强钩子

## 2. 线索回收

**触发**：调查中
**结构**：
- 铺多处线索
- 辨真伪去干扰
- 串联关键证据
- 逼近真相
**要点**：回收要有铺垫，忌天降证据

## 3. 反转复仇

**触发**：发现旧怨
**结构**：
- 揭开加害者
- 布局反击
- 反杀夺回主动
- 彻底了结
**要点**：复仇需智谋，不靠运气

## 4. 身份迷局

**触发**：嫌疑人身份存疑
**结构**：
- 释放错位线索
- 逐步证伪
- 真相揭露
- 重新站位
**要点**：悬疑靠渐进揭示

## 5. 孤身破局

**触发**：被孤立/陷害
**结构**：
- 凭专业自证
- 借人脉翻盘
- 掌握核心证据
- 反将一军
**要点**：突出女主独立与专业能力

## 6. 真相揭露

**触发**：收网时刻
**结构**：
- 公开证据链
- 凶手崩溃
- 代价清算
- 余波与成长
**要点**：揭露要呼应伏笔闭环
