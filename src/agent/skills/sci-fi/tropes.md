# 爽点套路库

> 每个套路提供模板，Agent 写作时按情境调用。

## 1. 第一接触

**触发**：遇见外星/AI
**结构**：
- 谨慎试探
- 建立沟通
- 文化碰撞
- 合作或冲突
**要点**：接触要有文明差异质感

## 2. 科技奇点

**触发**：AI/技术突破
**结构**：
- 技术跃迁
- 社会震荡
- 伦理争议
- 新秩序
**要点**：奇点要讨论代价

## 3. 文明博弈

**触发**：星际利益冲突
**结构**：
- 外交角力
- 技术封锁反制
- 联盟重组
- 均势或战争
**要点**：博弈要有宏观格局

## 4. 赛博觉醒

**触发**：AI产生自我
**结构**：
- 意识涌现迹象
- 人机对峙
- 共存方案
- 新物种
**要点**：觉醒要哲学深度

## 5. 星际远征

**触发**：远航任务
**结构**：
- 组建舰队
- 穿越险域
- 发现真相
- 归来或留守
**要点**：远征要有孤独与壮美

## 6. 悖论解谜

**触发**：时间/因果异常
**结构**：
- 识别悖论
- 设计闭环
- 自洽收束
- 代价明了
**要点**：解谜需物理自洽
