# 题材层质量规则

> 由 quality_checker.register_genre_rules 注册。

## 规则清单

### G-01 科学自洽
- **检查**：设定符合已知物理或自洽公理
- **严重度**：block
- **修订提示**：伪科学破坏硬核感

### G-02 世界观严谨
- **检查**：文明/科技有内在逻辑
- **严重度**：block
- **修订提示**：设定随意拼接

### G-03 高智叙事
- **检查**：以智取胜，非运气
- **严重度**：warn
- **修订提示**：降智爽文化

### G-04 伦理深度
- **检查**：技术突破讨论代价
- **严重度**：warn
- **修订提示**：只炫技无思考

### G-05 尺度感
- **检查**：星际/时间尺度有体感
- **严重度**：warn
- **修订提示**：量级混乱

### G-06 不伪科学
- **检查**：无超自然破功
- **严重度**：block
- **修订提示**：硬科幻混玄学出戏

### G-07 节奏张弛
- **检查**：硬核与剧情交替
- **严重度**：warn
- **修订提示**：全程设定堆砌枯燥

### G-08 代价真实
- **检查**：技术有伦理/风险代价
- **严重度**：warn
- **修订提示**：无代价神器
