# 爽点套路库

> 每个套路提供模板，Agent 写作时按情境调用。

## 1. 末世降临

**触发**：灾难爆发
**结构**：
- 前兆铺垫
- 秩序崩塌
- 主角抢占先机
- 首批生存
**要点**：降临要有真实混乱感

## 2. 囤货准备

**触发**：预见/先知
**结构**：
- 抢购物资
- 建安全屋
- 储备异能
- 度过初期
**要点**：囤货要有清单与策略

## 3. 基地基建

**触发**：站稳脚跟
**结构**：
- 选址防御
- 招募幸存者
- 分工建设
- 城邦成型
**要点**：基建要有成长曲线

## 4. 绝境求生

**触发**：被围困
**结构**：
- 分析威胁弱点
- 以异能/环境破局
- 惨胜
- 吸收晶核
**要点**：求生靠智不是运气

## 5. 团队集结

**触发**：遇可信之人
**结构**：
- 考验忠诚
- 分工互补
- 共御外敌
- 核心班底
**要点**：队友要有独立人设

## 6. 反攻扩张

**触发**：实力足够
**结构**：
- 清剿威胁
- 收复领地
- 建立秩序
- 新纪元
**要点**：反攻要有阶段性
