# 题材层质量规则

> 由 quality_checker.register_genre_rules 注册。

## 规则清单

### G-01 生存逻辑
- **检查**：资源/威胁符合末世常识
- **严重度**：block
- **修订提示**：违背生存逻辑出戏

### G-02 资源合理
- **检查**：物资消耗与获取平衡
- **严重度**：warn
- **修订提示**：无限物资崩设定

### G-03 基建进度
- **检查**：基地有清晰成长曲线
- **严重度**：warn
- **修订提示**：一夜城建虚假

### G-04 不圣母
- **检查**：主角取舍有狠劲，不滥善
- **严重度**：warn
- **修订提示**：无脑收留拖累剧情

### G-05 战力校验
- **检查**：异能/晶核等级对标清晰
- **严重度**：block
- **修订提示**：战力崩坏

### G-06 队友人设
- **检查**：队友有独立作用不工具化
- **严重度**：warn
- **修订提示**：队友扁平

### G-07 威胁递进
- **检查**：威胁随阶段升级
- **严重度**：warn
- **修订提示**：一直同一强度乏味

### G-08 爽点节奏
- **检查**：每 N 章至少一生存/建设爽点
- **严重度**：warn
- **修订提示**：长期压抑
