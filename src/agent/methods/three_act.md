# 三幕结构（Three-Act Structure）

本模板以「三幕」组织全书：**设置（Setup）→ 对抗（Confrontation）→ 解决（Resolution）**，每幕聚焦明确的叙事任务，章节递进与支线切换都服务于此。

## 第一幕 · 设置（约前 20–25%）

- 建立世界规则与主角处境：让读者快速理解"这是什么世界、主角是谁、差什么"。
- 抛出**激励事件（Inciting Incident）**：在第 1–3 章内让主角被动或主动卷入核心冲突，形成黄金三章钩子。
- 明确**核心问题（Dramatic Question）**：全书要回答的那个问题（如"他能否复仇/登顶/回家"），后续所有支线都指向它。
- 结束于**第一幕转折点（Plot Point 1）**：主角做出不可逆选择，进入对抗。

## 第二幕 · 对抗（约 45–60%）

- 主角为实现目标反复努力，**挫折递增**：每 3–5 章一次小失败/代价，压力曲线逐级抬升。
- **中点（Midpoint）**：约第 50% 章，发生重大反转（身份暴露/盟友背叛/目标变化），从"被动反应"转"主动进攻"。
- 引入副线（支线）但要回扣主线：每条支线最终都要服务于核心问题。
- 结束于**第二幕转折点（Plot Point 2）**：最大挫折（"一切都完了"），为第三幕蓄力。

## 第三幕 · 解决（约 20–25%）

- 进入结局模式后：主线伏笔集中回收、支线快速收束、反派/对手的最终冲突。
- **高潮（Climax）**：全书最后一两个重大冲突章，主角用第二幕获得的成长/资源赢下核心问题。
- **收尾（Denouement）**：核心问题尘埃落定后的余韵——代价、改变、新生活，1–3 章内干净收束，不留悬空支线。
