# 爽点与情绪结构技法库

> 用法：高潮章/爽点章写作时参考。核心信条：**爽点 = 满足期待**；前面铺垫多少，后面爽点就有多少。

## 一、爽点核心公式

爽点 = 两个逻辑的冲突点：
- **大众逻辑**：对手不可战胜 → 恐惧/绝望
- **主角逻辑**：正好手痒/轻描淡写
- 落差越大 → 爽点越爽

## 二、爽点三要素（打脸场面的三角色分工）

| 角色 | 操作 |
|---|---|
| 吃瓜群众 | 用议论吹高对手逼格 → 震惊反应完成打脸升华 |
| 对手 | 嚣张到让读者恨 → 被打脸时才爽 |
| 主角 | 铺垫时低调 → 释放时干脆 |

## 三、铺放比与反应层

- 铺垫与释放的比例（铺放比）要合理：短铺垫快释放（3:1 以内适合单章小爽点）；长铺垫大释放（5:1+ 适合卷级大爽点）；
- 反应层拆解：质疑/轻视 → 震惊/打脸 → 强者重评 → 扩散传播。反应篇幅比（反应层字数/打脸动作字数）低于 1.5 = 爽感不足；
- 释放后追证：爽点释放后，反派/旁观者的真实态度要补一笔（行为+反应），不能打完脸就切走。

## 四、情绪弧线（章节情绪落点）

| 弧线类型 | 结构 | 适用 |
|---|---|---|
| 上升弧 | 期待 → 压力 → 释放（爽） | 逆袭/打脸/升级 |
| 下降弧 | 美好 → 崩塌 → 余震（虐） | 虐文/失去 |
| V 型弧 | 低谷 → 转折 → 反弹 | 重生/翻盘 |
| 波浪弧 | 多组小升小降交替 | 日常/群像 |

要点：
- 每章至少一个明确的情绪落点（爽/虐/燃/甜/惊），落点要服务于本章「目标情绪」；
- 情绪不能连续多章平直（追读力杀手）；高潮章可扩篇幅+多视角+慢镜头放大情绪；
- 期待感公式：情绪 + 情节（人设+动机）+ 信息差，三者缺一则不足。

## 五、质量自查

- [ ] 本章爽点有铺垫（读者等到了才爽）
- [ ] 释放干脆（铺垫完不拖沓）
- [ ] 有反应层（有人震惊/重评/传播）
- [ ] 情绪落点与细纲「目标情绪」一致
