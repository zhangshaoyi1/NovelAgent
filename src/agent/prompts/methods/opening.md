# 黄金三章开篇指导

> 用法：写第 1-3 章时注入。开篇的目标是让读者「留下来」——前 3 章必须立住人设、给足期待、亮出差异。

## 一、三大基点（前 3 章内全部完成）

| 基点 | 内容 | 作用 | 完成时机 |
|---|---|---|---|
| 人设基点 | 展示主角核心性格和处境 | 建立代入感和共情 | 前 3 章 |
| 切入点基点 | 主角遭遇的第一个冲突/机遇 | 制造紧迫感和阅读动力 | 最好第 1 章 |
| 金手指基点 | 展示主角独特优势 | 制造期待感和差异化 | 前 3 章 |

- 困境型先人设（共情入口），优势型先金手指（期待入口）；
- 切入点必须跟主线强相关，不能是随机事件；
- 第一章必须让读者知道两件事：主角目标 + 本书卖点。

## 二、必达指标（开篇前 3 章）

- [ ] 从故事最精彩、最有冲突的地方写起，不从背景介绍写起
- [ ] 主角三种状态选一：身处危机 / 令人羡慕 / 被丢入陌生环境
- [ ] 前 300 字主角登场，前 1000 字出现爽点或期待点
- [ ] 第一个冲突影响重大：事先点明解决的好处和不解决的坏处
- [ ] 背景信息分批释放，优先级：危机感 > 人设 > 金手指暗示 > 世界观

## 三、绝对禁止

| 禁止 | 理由 |
|---|---|
| 大段背景介绍 | 开头全是"缓"没有"冲突"，读者秒退 |
| 天气/风景开头 | 除非反差极大 |
| 出场 3 个以上主要角色 | 信息过载 |
| 插叙/切视角/回忆梦境 | 正叙为主 |
| 世界观详细解说 | 至少等到第一个一级结构结束 |
| 序章/楔子/引 | 除非以叙事为主、足够简短且与第一章逻辑紧密 |

## 四、开篇结构范例（困境切入型）

```
1. 主角处于不利处境（人设基点=共情入口）
2. 遭遇压迫/危机（切入点=紧迫感）
3. 金手指激活/展示（金手指=反转期待）
4. 初步解决问题但引出更大问题（钩子）
```

## 五、平台差异速查（写作时参考，advisory）

| 维度 | 番茄 | 起点 | 晋江 |
|---|---|---|---|
| 核心取舍 | 节奏 > 代入感 | 代入感 > 节奏 | 人设 > 情节 |
| 开头策略 | 强情绪+强噱头 | 人物铺垫+可慢热 | 角色魅力先立 |
| 爽点密度 | 每 2000 字一个 | 每 3000-5000 字一个 | 情感推进即爽点 |

## 六、常见问题速查

| 问题 | 症状 | 修正 |
|---|---|---|
| 信息传达不清 | 主角在哪/干什么/动机不明 | 开局交代处境，明确目标再进事件 |
| 人设逼格过低 | 见美女紧张/无意义内心戏 | 主角要有逼格，配角要有特色 |
| 情绪缺失 | 战斗枯燥/看几段不想读 | 战斗中穿插情绪——恐惧、愤怒、决心 |
| 金手指出场突兀 | 像写日记一样冒出金手指 | 用危机或困境触发金手指 |
