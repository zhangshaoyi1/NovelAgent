# 晋江文学城 Quality Rubric

## 评分标准

| 指标 | PASS 标准 | FAIL 标准 |
|------|----------|----------|
| 开篇代入 | 前 3 段建立主角视角与核心冲突/悬念 | 前 3 段纯背景交代或世界观铺陈 |
| 感情线张力 | 主线 CP 每 3 章有情感推进或拉扯事件 | 连续 5 章感情线原地踏步 |
| 人设立体 | 主要角色行为有内在动机支撑，无工具人化 | 角色行为仅服务于剧情需要 |
| 文笔质感 | 描写细腻有画面感，文笔与题材调性匹配 | 大量重复句式/流水账/堆砌辞藻 |
| 情节密度 | 每章有至少 1 个信息增量或情感节点 | 连续 2 章无信息增量 |
| 三观导向 | 价值观表达符合平台导向（不美化违法行为） | 触碰平台内容红线 |
| 完读追更 | 章末留有情感钩子/期待感 → 追更动力强 | 连续 3 章结尾无期待感 |

## 使用方式

- 评审时以此标准校准判断。
- rubric 违例默认报 warn，不直接 block；同一指标连续多章 FAIL 可升级为 block。
- 晋江读者偏好女频向、情感浓度高、人设鲜明的作品；文笔质感权重高于番茄类快节奏平台。
