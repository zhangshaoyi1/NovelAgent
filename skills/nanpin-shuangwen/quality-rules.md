# 题材层质量规则

> 由 quality_checker.register_genre_rules 注册。男频爽文以"情绪满足"为核心验收标准。

## 规则清单

### G-01 爽点密度
- **检查**：每章至少含 1 个明确爽点（打脸 / 逆袭 / 收获 / 身份反转）；每 3 章至少 1 次大爽点
- **严重度**：warn
- **修订提示**：缺爽点的章节补充释放段，或并入前后章；勿让铺垫章节无落点

### G-02 打脸节奏
- **检查**：被轻视 / 被压制后须在合理篇幅内完成打脸，忌无限拖延
- **严重度**：warn
- **修订提示**：压缩铺垫，把释放点前移；用章末钩子替代"下一章才打脸"

### G-03 无虐主
- **检查**：主角吃瘪 ≤ 1 章，且无重伤 / 永久损失 / 长期屈辱；憋屈只为铺垫爽点
- **严重度**：block
- **修订提示**：虐主段落改写为"外人以为主角输了，实则主角在布局"；删除真实屈辱

### G-04 金手指自洽
- **检查**：金手指具备类型 / 成长曲线 / 代价 / 上限，逻辑闭环不自相矛盾
- **严重度**：block
- **修订提示**：补全代价与上限，避免"无敌流"导致后期无张力

### G-05 反派智商
- **检查**：反派动机与行为合理，不无理由降智送人头（喜剧设定除外）
- **严重度**：block
- **修订提示**：给反派合理动机；打脸靠主角布局而非反派犯蠢

### G-06 期待感管理
- **检查**：章末保留钩子（悬念 / 反转 / 新底牌），禁止平淡收章
- **严重度**：warn
- **修订提示**：章末加一句钩子（新危机 / 新底牌 / 反派后手）

### G-07 开篇抓人
- **检查**：前 500 字出现冲突 / 悬念 / 反差（如退婚 / 重生觉醒 / 系统激活）
- **严重度**：block
- **修订提示**：把最反差的一幕前置，删去缓慢的环境铺陈

### G-08 装逼分寸
- **检查**：装逼有实力 / 信息差支撑，读者感到"爽"而非"尬"
- **严重度**：warn
- **修订提示**：给装逼加合理依据；避免无上下文的炫技与百度式台词

### G-09 战力对标
- **检查**：阶层 / 战力序列前后一致，越级杀有合理解释
- **严重度**：block
- **修订提示**：建立战力对标表；越级须标注金手指 / 计谋 / 克制关系

### G-10 节奏不拖
- **检查**：无注水冗笔，单章推进明确（铺垫→释放或释放→新钩子）
- **严重度**：warn
- **修订提示**：删减与爽点无关的心理描写与重复铺垫

### G-11 信息差运用
- **检查**：爽点多由"主角已知、他人未知"的信息差驱动
- **严重度**：warn
- **修订提示**：让读者与主角同频（知道底牌），让配角蒙在鼓里，制造认知差快感

### G-12 情绪曲线
- **检查**：章节 / 段落存在"憋屈→期待→释放"的情绪起伏，非一条直线
- **严重度**：warn
- **修订提示**：在释放前补一段压制（轻视 / 危机），拉大落差以提升爽感
