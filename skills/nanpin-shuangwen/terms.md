# 术语表

- **爽点**：让读者获得情绪满足的关键情节或瞬间（打脸 / 逆袭 / 收获 / 身份反转）
- **打脸**：原本轻视主角的人被现实反噬，认知被强行纠正
- **装逼**：主角展现超出他人预期的能力或地位，制造震惊
- **扮猪吃虎**：隐藏真实实力 / 身份，先被低估再反杀
- **金手指**：主角独有的外挂优势（系统 / 传承 / 重生记忆 / 异能 / 签到 / 神豪）
- **系统**：以任务 / 奖励 / 面板形式给予指引与增益的金手指
- **无敌流**：主角战力碾压同阶，侧重从容碾压的爽感
- **重生**：带着前世记忆重启人生，先知信息差为核
- **退婚流**：开局被退婚羞辱，成为逆袭起点（经典男频开场）
- **神豪**：以无限财富碾压物质鸿沟的爽点类型
- **签到**：每日 / 每处签到领取奖励的稳定成长机制
- **气运**：角色命运眷顾度，影响机缘与对手失误
- **虐主**：让主角受辱 / 受创的段落；男频中属于高危"毒点"
- **毒点**：令读者弃书的不适设定或情节（如长时间虐主、降智、绿帽）
- **期待感**：读者对"即将发生好事"的预期，由悬念与信息差维持
- **钩子**：章末 / 段末的悬念或反转，驱动追读
- **章末悬念**：章节结尾保留未解张力，迫使读者翻下一章
- **节奏**：情节推进的快慢与爽点分布的疏密
- **信息差**：主角掌握而他人未知的信息，是男频爽感的核心引擎
- **降智**：配角 / 反派无理由变蠢以衬托主角，过度使用即成毒点
- **伏笔回收**：前文埋下的线索在后期爽点处兑现，强化闭环爽感
- **情绪曲线**：憋屈 → 期待 → 释放的起伏波形，决定爽感强度
- **战力对标**：角色 / 势力间实力层级的对应关系，保证打脸与越级可信
