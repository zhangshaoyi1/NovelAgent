# 爽点套路库

> 每个套路提供模板，Agent 写作时按情境调用。

## 1. 重生觉醒

**触发**：主角死于前世
**结构**：
- 回到关键节点
- 认清仇敌
- 制定翻盘计划
- 低调布局
**要点**：觉醒要带前世情绪厚度

## 2. 先知布局

**触发**：利用未来信息
**结构**：
- 押注正确方向
- 避开前世坑
- 提前积累资源
- 步步领先
**要点**：先知需有信息边界

## 3. 打脸仇人

**触发**：仇人再次压迫
**结构**：
- 以Prepared反制
- 当众揭其恶
- 夺回主动权
- 仇人崩塌
**要点**：打脸要有前世因今世果

## 4. 弥补遗憾

**触发**：重要之人将逝/误
**结构**：
- 提前介入
- 改变结局
- 情感释放
- 关系修复
**要点**：遗憾弥补要真挚不煽情过度

## 5. 商业/仕途逆袭

**触发**：重走人生路
**结构**：
- 选对赛道
- 借势崛起
- 碾压旧轻视者
- 站上顶峰
**要点**：逆袭逻辑要自洽

## 6. 结局改写

**触发**：终极对决
**结构**：
- 揭穿前世真相
- 彻底清算
- 新时间线稳固
- 圆满/升华
**要点**：改写要呼应因果闭环
