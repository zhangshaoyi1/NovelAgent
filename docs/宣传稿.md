# NovelAgent 宣传稿

## 短版（社交媒体 / 社群推广，约 300 字）

**别再用「AI 写作工具」写长篇了——你需要的是一个编辑部。**

写过长篇的人都知道：真正的敌人不是灵感枯竭，而是设定崩塌与记忆流失。第 80 章的女主性格，早已和第 8 章判若两人；第 3 章埋的伏笔，写到完结也没人记得回收。

**NovelAgent** 是一个共创式长篇小说写作 Agent，它给你的是一支完整的创作团队：**25 位专家 Agent**——世界观架构师、地理志官、力量体系师、时间线管家搭起可计算的世界；卷纲策划、章节编排师、冲突设计师、伏笔管家推进情节；润色与审校组把守每一章的质量门禁。你只管当总编，方向与拍板始终在你手里。

- 七步向导走通创作闭环：世界观 → 讨论 → 架构 → 大纲 → 角色 → 逐章成稿
- 世界先于文字：人物处境、势力消长、伏笔埋收全部结构化推演，写完一章，世界前进一格
- 实时写作间：日志、时间线、成本预警全程透明
- 一键续写、伏笔逾期自动告警、快照回滚随时可逆

打开网页就能写。`pip install -e ./agent && novel-agent web`，你的第一本 30 万字，今晚开更。

## 长版（发布页 / 公众号，约 1200 字）

### 给认真想写完一本书的你

每个人心里都有一本长篇小说。但统计数据从来没人统计过的是：绝大多数长篇，死在 10 万字之前。

不是作者不努力，而是长篇是一场对抗熵增的战争。人物越来越多，关系越来越乱；世界观越铺越大，前后矛盾越来越多；埋下的伏笔像散落的线头，再也捡不起来。人类作者靠笔记、靠大纲软件、靠记忆和自律硬扛——现在，你可以把这场战争的后勤，交给一支 AI 编辑部。

### 不是写作工具，是创作团队

NovelAgent 的核心哲学只有一句话：**它不做万能的「AI 写手」，它做编制完整的创作团队。**

点开「Agent 阵容」页，你会看到 25 位专家各司其职：

- **世界构建组（6 人）**：世界观架构师、地理志官、人物设计师、设定考据员、力量体系师、时间线管家——他们共同维护一台「世界状态机」，守护设定自洽，揪出前后矛盾；
- **情节叙事组（7 人）**：卷纲策划、章节编排师、冲突设计师、伏笔管家、节奏调度官、导演 Agent、路线规划师——在规则约束下让剧情自然涌现；
- **成文润色组（5 人）与审校把关组（7 人）**：从爽点密度到 OOC 检测，从 AI 味到注水判定，每一章成稿都要过七道质量门禁，不通过自动修订。

它们不是 25 个聊天窗口，而是围绕**同一个世界状态**协同工作。你担任总编：每一次重大决策，它们都会停下来等你拍板。

### 世界先于文字

普通 AI 写作是「顺着往下编」，编到后面忘了前面。NovelAgent 先建立**一个可计算、可追溯的世界**，再让文字从中生长：

- 人物处境、势力消长、物品去向，被结构化地记录与推演；
- 每条伏笔由**确定性状态机**管理——埋设、强化、回收三态流转，逾期未回收自动亮红灯；
- 连续性账本随时可查：谁知道什么（信息差）、哪些事项未闭环、章节之间如何交接；
- 改了世界观？下游的大纲和已写章节会自动标记「待复核」，由 AI 逐条列出受影响的条目，**绝不让设定悄悄烂掉**。

写完一章，世界就前进一格。下一章，永远基于一个自治的当下。

### 打开浏览器，就是你的创作间

零配置门槛：`novel-agent web` 一条命令启动网页工作台，所有配置都在网页上完成——模型管理页可视化添加多个大模型、一键测连通；项目空间随意切换数据目录；连提示词都有版本面板。

- **七步向导**：开新书 → 脉络讨论 → 故事架构 → 确认架构 → 创作大纲 → 角色设计 → 写章节，每步一键生成、就地修改，新手也能一步步走通；
- **实时写作间**：三栏布局，左边本章上下文，中间章节流水，右边实时日志。点一下写一章，也可以「⚡ 自动续写」一口气推进十几个章节，成本预警全程可见；
- **世界关系图谱**：力导向图可拖拽编排，人物 / 势力 / 地点 / 物品 / 伏笔五类节点一目了然，还能一键从项目数据自动生成；
- **多题材混搭**：修仙+武侠+科幻？题材设定自动合并，同名设定冲突生成冲突卡，由你逐条裁决，最终收敛成这本小说独有的世界规则；
- **随时可逆**：快照、回滚、归档——写歪了退回第 20 章重来，写过的章节一个字都不会丢。

### 从一句话到完本书

给它一句话：「废柴少年偶得神秘传承，踏上逆天修仙路。」它就能走完世界观、大纲、角色、逐章写作的全流程；写完还会做「不崩」七维终审和「迷爱看」六维评分，缺陷自动回溯修复。最后一键导出 TXT / Markdown / EPUB。
