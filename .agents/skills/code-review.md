# Code Review Skill - 代码审查检查清单

> 目标：统一代码审查标准，确保代码质量和架构一致性。

---

## 架构检查

- [ ] 依赖方向是否正确？`base → client → core → agents → workflows`
- [ ] 新模块是否遵循了"降级不阻断"原则？
- [ ] 是否保持了向后兼容性？
- [ ] 是否遵循了单向依赖原则？

## 代码质量

- [ ] 命名清晰，符合 Python 惯例（snake_case / PascalCase）
- [ ] 没有不必要的注释或死代码
- [ ] 函数 / 方法职责单一
- [ ] 异常处理符合项目风格（try/except 降级，不静默吞异常）

## 测试

- [ ] 新增功能有对应的测试覆盖？
- [ ] 测试运行通过？
- [ ] 测试覆盖了边界条件（LLM 不可用、空输入、异常路径）？

## 文档

- [ ] 修改了架构 → 更新了架构文档？
- [ ] 新增了命令 → 添加了 `@command` 装饰器？
- [ ] 修改了 API → 更新了文档字符串？
- [ ] 非平凡修改 → 创建了 Agent Note？

## 提交

- [ ] 提交信息清晰，包含修改动机
- [ ] 没有混杂不相关的修改
- [ ] 没有提交敏感信息（API Key / 密码）
