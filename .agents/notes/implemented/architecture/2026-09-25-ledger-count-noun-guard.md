# Agent Note: 计数事实的名词切错守卫（账本不得收比况/动词/截断片段）

Status: implemented

## Problem

`m5_persist._extract_chapter_facts` 的计数通道（`_COUNT_RE` + `_pick_noun`）以
「数量 + 实体性后缀名词」为判据，后缀白名单是**单字**匹配（人/符/印/钉/袍/环/傀…），
于是任何以该字收尾的 2-4 字片段都被当成实体名入库。实弹（灵荒工坊 2026-09-24
web 任务 `20260924235900-5adfac`，exit_code=2 / escalated）：

- ch002「『属性对冲』**四个字像烙印**一样刻在他记忆里」⇒ 抽出
  `world/字像烙印.count=四个`（实体名本身是病句切分产物）；
- 评委拿这条脏台账去比对 ch051「符号出现在**三个**地方，三种标记」⇒ 判
  **数量直接冲突**（`logic_holes = 1 > 0`，**硬指标不可放宽**）；
- 同时 `golden_total = 54 < 60`（金三 B4）触发 escalated，回溯窗口修不到开头。

全账本审计（564 条事实 / 74 条 count）另发现同族脏实体 15 个：
`能翻盘`（「一个能翻盘的机会」）、`身穿灰袍`/`穿灰袍`/`穿青袍`（「一个身穿灰袍的中年」）、
`伸手`（「一人伸手探向」）、`数字钉`（「一个数字钉死」）、`已解锁`（「二层已解锁」）、
`粗劣傀`/`标准化傀`/`枚嵌入傀`（傀儡被截断）、`线五个人`、`月有人`、`节点呈环`、
`零件都符`、`半人`。

危害不止「多一条噪音」：脏实体进账本后会**持续参与评委判定**，把正常正文判成
前后矛盾（本书 `setting_consistency_high` 历史复现 2 次、`logic_holes` 3 次），
且回退重写会再触发一次抽取 ⇒ 同一误报永久复现。

## Decision

在 `_pick_noun` 的两处判据上收紧，**只加守卫、不改判据结构**：

1. `_NOUN_BAD` 由「虚词/副词」扩为三类禁用字：虚词副词 + **比况词/能愿动词/动词**
   （像似能翻伸呈都已穿嵌解有）+ **数量修饰**（数个半）。
2. 新增 `_INCOMPLETE_CHARS = frozenset("傀")` 截断守卫：候选末字是「只作构词成分、
   从不单独作名词收尾」的汉字即丢弃（`粗劣傀` 截自 `粗劣傀儡`）。

**尺度（实测教训）**：凡有正当实体反例的字一律不进 `_NOUN_BAD`——`劣` 曾被收进，
于是「三枚劣品灵石」（正当事实，ch014）被一并挡掉。宁可少抽（漏一条 count 事实无
下游危害）也不可抽错（脏实体污染评委判定）。`劣`/`质` 因此**不在**表内，
`劣质石`/`紫檀木书`/`残破符`/`音符` 四个同类噪音保留（无害，且当前抽取器仍会产出，
删台账会破坏「账本可重放」不变式）。

## Alternatives considered

**Why not 继续用后缀白名单逐字扩充（加 案/箓/音…）？**
后缀匹配天然无法区分「烙印」的印与「玉印」的印；逐字扩充是无底洞，且每加一字都要
重新评估是否误伤正当实体（`劣` 就是实例）。

**Why not 加「候选后接汉字即判截断」的通用守卫？**
实测会误伤：`三个外门弟子快步走来` 里 `外门弟子` 后接 `快`，属正常收尾。
通用规则不可行，故只对「不可能单独收尾」的字建小表。

**Why not 让 LLM 结算兜底筛掉脏实体？**
确定性抽取器是**零 LLM 成本**的账本底座；引入 LLM 判名词合法性会把成本与不确定性
带进每条事实，且失败时账本会整体缺项。

  「每章 ≤3 条」配额而被正常抽出。

  截断名词 / 边界不误伤），含 `劣品灵石` 反例锁定。
