# Agent Note: 金三门禁估计量去偏（逐章多采样均值 + 单维触底复核）

Status: implemented

## Problem

黄金三章门禁（B4）在**三章拼接超 10000 字**时走 fallback：逐章独立评分、逐维取 min、
总分取 min（`reader_appeal.gate_first_chapters._score_sample`）。两个缺陷叠加，
使**达标书被误熔断**：

1. **对单次采样取 min ⇒ 系统性低估**。六维判定是单次 LLM 评分，单维噪声
   σ≈8-10（实测同一内容同一维跨度 35↔58）；对带噪单样本取 min-of-3
   约低估真值 7-10 分。
2. **单维触底线没有方差抑制**。贴线复核（`_borderline` / `recheck_borderline`）
   只看**综合分**是否落在 60±5，单维落在触底线 40 附近**永不复核**——
   而单维恰恰是方差最大的量。

**实证（2026-09-25 灵荒工坊 ch001-003，内容零改动）**：

| 估计方式 | 综合 | 爽点密度 |
|---|---|---|
| 单次采样取 min（旧） | 57 / 56 / 58 | 38 / 38 / 32 |
| 逐章均值再取 min | ≈68 | 42 |

即：同一内容，旧估计量给出「不达标」（爽点 38 < 触底 40、综合 < 60），
换成逐章均值即全维过线。判定噪声被当成了内容缺陷。

## Decision

两处修改，语义不变（仍是「对最差章判定」，只是改判**章节的真实分数**而非抽样噪声）：

1. **逐章多采样取均值**（`GOLDEN_FALLBACK_SAMPLES = 2`）：fallback 路径下每章先采
   2 次、逐维取整均值，再参与 min。取 2 是去偏与成本的折中——回退路径只在内容
   指纹变化时执行一次且结果进缓存；离线样本不参与均值（保持 `llm_used=False` 短路语义）。
2. **单维触底线纳入复核**：
   - 批末 `_borderline(total, online, dims)` 增加「任一维落在 `GOLDEN_DIM_FLOOR ±
     GOLDEN_BORDERLINE_BAND`」条件；
   - 写时 `recheck_borderline` 同口径（`APPEAL_DIM_FLOOR ± band`）。
   两处复核均为「再采一次取逐维均值」，失败/离线保留首评（复核是方差抑制，不是新门禁）。

## Alternatives considered

**Why not 把「逐维取最差」改成「取均值/中位数」？**
那会改变门禁语义（拍板 #3 明确「取最差章」是有意为之：开局最弱的一章决定读者是否留下）。
本次只修**估计量**（对真实分数取最差），不动判定口径。

**Why not 提高 `GOLDEN_JOIN_CHAR_LIMIT` 走拼接单次评分（省调用）？**
`score_chapter` 内部本就按约 10000 字截断，拼接路径等价于「只评第一章开头」，
不能代表三章水平——这正是 fallback 存在的原因。

**Why not 只在缓存层做「同指纹重评取最好」？**
等于给门禁开后门（取最好 = 取最宽），与不可放宽的硬指标语义冲突；
且会掩盖真实低分（本书 ch002 爽点确有真缺陷，是靠内容修复而非取最好解决的）。

## Consequences

- 回归：`tests/test_golden_recheck.py` 新增 3 项（单维触底触发复核 / 远离触底不复核 /
  写时同口径）、`test_g6_golden_three.py::test_g6_golden_join_fallback_worst` 按
  2 次/章更新；`-k "golden or appeal or evaluator"` **92 passed**。
- 成本：fallback 路径每章多 1 次调用（3 章 → +3 次），仅在内容指纹变化时发生，进缓存。
- **未解决（本 Note 不覆盖）**：去偏后实测仍为 58/61、爽点 33-36 —— 因为本书开篇的
  内容真值就压在触底线上（细纲对 ch001/ch002/ch003 **明写「爽点=无」**，属刻意慢热设计）。
  估计量能去掉偏差，但不能把压在阈值上的内容推过去。**门禁标定（触底线 40 / 阈值 60）
  与本书慢热开篇的设计意图是否相容，需作者裁决**——见
  `proposed/architecture/2026-09-25-hard-metric-judge-variance.md`（同一方差问题的
  另一个出口：不可放宽硬指标由单次 LLM 判定）。
